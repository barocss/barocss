# Select imported SVG paths

Use the Path selector to choose an imported path by its actual ID. Select its cubic command and C1 or C2, then enter coordinates and apply. Paths without cubic commands display no cubic controls. The host retains its two-edit budget.

The selector keeps a valid current ID when a candidate or document is adopted. Otherwise it prefers ArcPath, then a path with a cubic command, then the first path. Current zero-asset documents can reopen when their path uses another ID. Import conversion and source provenance keep their existing authority.
