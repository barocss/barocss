# D1254 — Move the upper cap of a rectangular taper

2026-11-14 · FULL · P5, rows 08 and 31 · [#2264](https://github.com/barocss/barocss/issues/2264)

Offset face handles one named +Z cap on a verified closed rectangular taper authored by Draft, Draft Extrude or an earlier direct offset. The four authenticated native wall planes determine the new rectangular section. The kernel keeps the opposite cap, loops, names and entity tolerances. When a wall's existing surface chart contains the new trim it keeps that chart. Otherwise it extends the support and checks the direction against the existing linear policy. The solid must pass strict B-rep validation. The operation refuses cap crossing, collapsed width, unrepresentable motion and coordinate overflow.

The new operation is one signed History node in the existing native format. It retains the original cap signature and refuses automatic replacement by another face. Editing changes only the distance. Straight-prism and cylinder offsets keep the existing sketch/extrude/Boolean recipe. Native File and Project Open use the same pre-adoption check for active tapered offsets; saved structural validation also checks offsets in nested and pending parts.

- **PASS, actual Studio** Opened authored 20 × 10 × 12 mm rectangular stock with 15° Draft and clicked its upper cap. Applied +2 mm and edited to −2 mm in History. A +8 mm edit refused and preserved the accepted part. Undo returned directly to +2 mm, Redo restored −2 mm, and native Save, fresh File Open and History replay kept −2 mm and both authored source nodes. Opening a signed file with +8 mm refused before replacing the displayed part. A separate straight box created the legacy three-step recipe.
- **PASS, physical proof** For slope s = tan(15°), the section area is (20 − 2sz)(10 − 2sz). Integrating it to z = 14 and z = 10 gives 1487.1391966703354 and 1291.8814490059528 mm³. Studio and native volume agree within 3e−13 mm³. The two cap levels, wall normals, plane offsets, native names and eight corners agree. The largest strict edge-to-surface gap is 3.553e−15 mm. The native control includes asymmetric two-wall Draft and translated stock reduced to about 2e−7 mm, then lengthened 1 mm. Its original wall charts are preserved and its final vertex differences are within 1e−10 mm of the direct result.
- **PASS, regressions** 42 kernel, 42 Model and 16 Studio file tests. Includes rejection of an unsigned, merged-name or wrong-parent recipe, name and signature renumbering through duplicate and placed assembly, and validity/retention checks for nested File or Project admission. Package type-checks, selected lint, code shape, Vite build, driver syntax, targeted links and diff checks pass. A separate High review found the pre-adoption and near-base conditioning gaps, which the final implementation covers. In the external mutation check, replacing the sloped continuation with a straight wall extension is detected.
