# Public sprite image source: native observation

Exact base: locally integrated #802 `000c9c9ecea1deafcc7a6ca71531a06e2990b975`. This observation covers the independent native #806 implementation before Integration. The compiled package is experimental and unpublished.

Node 22.22.0 `pnpm --dir packages/barocss-canvas2d build:library` passed with a 130.1-KiB browser entry and declarations. Independent compiled-consumer `tsc -p packages/barocss-canvas2d/consumer/tsconfig.json` passed. `sprite-image-source-probe.mjs` passed ID+crop replacement, omitted/null crop clearing, copies, reconstruction/further editing and 12 atomic invalid refusals. Existing display-tree, sprite-crop, sprite-size and document probes were run for final regression verification.

The actual headless Chromium 155/WebGL2 page registered two different top-to-bottom 2×2 RGBA8 assets, 16 bytes each, with nearest sampling and DPR2. AtlasA began as a red-cell crop over a yellow underlay. Switching the same Sprite to AtlasB with an omitted crop cleared the prior crop. Pixel/hit samples became `(30,30)` magenta/Sprite, `(70,30)` yellow/Back through transparent alpha, `(30,70)` cyan/Sprite and `(70,70)` white/Sprite. Setting `{x:1,y:1,width:1,height:1}` on AtlasB made all four samples white/Sprite. A real pointerdown at `(30,30)` routed Sprite → Team → stage. Submitting missing ID `Missing` or an AtlasB crop beginning at x=2 returned `INVALID_ASSET`; both retained the accepted AtlasB full-image frame/pixels/hits. The host restored the valid handle source after each refusal. The renderer then removed unused AtlasA, leaving AtlasB's 16 bytes intact.

The browser downloaded the actual [879-byte v1 document](source-document.json), reloaded the page and chooser-Opened it into a fresh generation-2 canvas/renderer/tree. The restored Sprite used full AtlasB; AtlasA was absent, and all 16 AtlasB bytes plus four pixel/hit samples matched. The host explicitly registered AtlasA on that fresh renderer, then edited the reconstructed handle back to it. Final samples were red/Sprite, yellow/Back through alpha, blue/Sprite and green/Sprite. The [reopened and switched screenshot](reopened-switched.png) was inspected. Final browser console had zero errors and warnings. Browser and server were closed.

This fixed two-asset flow does not establish streaming, spritesheet metadata, animation, general filtering, broad-device support, integration or release acceptance.
