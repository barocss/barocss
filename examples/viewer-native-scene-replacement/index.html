About native canvas keys

Keys work in an idle ready original native scene while the canvas has focus. F fits current sampled visible geometry with its display poses. If all bodies are hidden, F keeps the accepted view and reports that there is no visible geometry. Escape clears the selected Surface or Curve, its point and derivative reports, and their U/V/t drafts. The captured chord, latest SDK measurements and File choices remain. Keys do not act in text fields or other source modes. Shift, Alt, Control, Meta, repeat and composition inputs are ignored. Keyboard controls are independent of the pointer navigation checkbox. Presentation loss pauses these keys; retained CPU inspections remain separate.

About native object selection

Enable selection, then tap a visible native Surface or Curve. A blank tap clears selection. Dragged or cancelled taps are ignored. Selection starts off and works only in an idle ready native scene. This is approximate screen selection. An ambiguous hit can include adjacent triangles of the same Surface; the public picker winner is selected. Enter the original U/V or t separately: the screen hit does not fill these exact fields or inspect a point automatically. A different object starts at its original domain midpoint; the same object keeps its reports and drafts. Captured chord, SDK measurements and File choices remain. Keyboard and pointer navigation are independent. Presentation loss pauses screen selection; retained CPU inspections remain separate.

About native view navigation

Open or load an original native Source0 scene, then enable navigation. Drag with the primary button to turn the view, Shift-drag to pan, or use the wheel to zoom. Navigation starts off and is available only for an idle ready native scene. Moving the view keeps the original geometry, selection, parameter drafts, point, chord, derivative reports and File choices. It does not select a new object or change native parameters. New source acceptance ends the old gesture, even when its content is identical. A failed source candidate keeps the accepted scene. Navigation pauses after presentation loss; retained CPU inspections remain separate.

About local original files

Choose a local Source0 file, then select Open. Choosing or discarding a file does not change accepted geometry. Open uses the whole original source in mm and displays all one to four admitted Surface or Curve objects with a fitted view. Files must contain 1 to 65,536 UTF-8 bytes. The filename and extension do not determine the geometry. Unsupported or invalid files leave the accepted original scene in place when presentation recovery is available. This opens native geometry, without Face topology, a saved document, Shell, assembly or editing history. It does not upload or save your file.

About IGES geometry files

Choose an IGES file, confirm that its authored XYZ matches this Y-up view, then select Open. Choosing or discarding a file changes no accepted geometry.
Open retains the complete original file and import result. It displays all one to four admitted native Curve or Surface objects with a fitted view, without rotating or normalizing their coefficients.
The supported writer profile uses IGES 5.3 ASCII, exact 80-column records with LF, millimetres and scale 1. Raw files may contain up to 1 MiB. Unsupported formats or display profiles leave the accepted data in place when presentation recovery succeeds.
Generated native IDs identify the imported objects; directory labels may be truncated. Import does not recover original authored IDs, source spelling, topology or editing history.
After IGES Open, the source download offers generated imported Source0, not the raw IGES file. File choices and retained CPU provenance can remain available after presentation loss; new Open needs an available Viewer.

Native derivative report


About selected native derivatives
Use the selected native point's original U/V or t fields above. This report shows the original authored XYZ point in millimetres and raw dP/dU, dP/dV or dP/dt vectors in millimetres per original dimensionless parameter.
The vectors are not normalized. They do not include display pose or scale and are not outward normals. Zero vectors are valid. Endpoints use the interior span; an exact C0 interior knot cannot supply a first derivative.
Invalid active drafts keep the last completed report. Reset clears only this derivative report and keeps drafts, point, chord, measurements and File choices. Selection or source changes clear the report; view changes keep it. A retained selected CPU object remains available after presentation loss. No continuity, global accuracy or topology certificate is implied.

About captured native chords
Use the selected native point's U/V or t fields above. Capture the first point, choose another object or parameter, then capture the second point to measure their original authored straight-line distance in millimetres. A third capture starts a new pair.
The first point remains across selection, visibility, view and display pose changes while its whole original source remains current. It does not restore hidden selection. A new source, Clear or Dispose clears the captured points; a failed candidate keeps them.
The second capture updates the SDK's latest native measurement. Reset clears only these captured points, keeping the parameter drafts, separate point report and latest measurement. A report error after a successful measurement does not undo that SDK cache.
This is an original native chord, not arc length, a nearest-geometry distance or a distance after display poses. Retained CPU points may be measured after presentation loss; new GPU selection stays blocked. No precision or topology certificate is implied.
