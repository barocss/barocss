# Choose an example by its task

Find a starting input, open its live result, then follow the matching guide. Choose a library to see its tasks together, a language to practice declarations, or an integrated workflow to follow data between public library contracts.

| View | Choose it when you want to… |
| --- | --- |
| [By library](./library) | Learn a package operation or find all learning purposes for a primary library |
| [Language practice](./language) | Edit CAD source, GPU scene styles or material expressions and inspect their meaning |
| [Integrated workflow](./integration) | Follow native CAD geometry through sampling and GPU display |

An API task focuses on public operations such as scene edits, manual steps or document Open. A language task focuses on what the complete source means. An integrated task focuses on the handoff between libraries. A browser host, shared canvas component or backing fixture alone does not make a task an integrated workflow.
