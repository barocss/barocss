# Producer, accepted geometry and recording mapping

The actual persistent apply primitive keeps its numerical body updates unchanged. It returns one producer contribution from that actual vector and common anchor: onA uses the vector subtracted from A, onB uses the vector added to B, and each moment is independently evaluated as its own anchor cross its own actual vector. The code never assigns onA moment by negating onB moment. This first path naturally has reciprocal vectors and moments because it uses a common anchor.

warmStartPoint returns that contribution. solvePersistentPoint combines only its actual normal and tangent application returns; it does not return the final cache as a report. World combines those deltas once in a fresh candidate pair map. A nonzero application flag survives cancellation; zero-only calls do not create a pair. The trace hook separately records actual arguments/poses/velocities and both actual side vectors/anchors. It is not read by producer code.

The B and FACE/EDGE dispatcher force path, 8 outer passes, 8 alternating inner iterations, restitution target, warm cache copying and friction equations remain the old phase graph's law. B depth remains SAMPLED_PATCH_DEPTH, with the old independent fixed-direction full-support overlap gate. No observer answer changes that producer input. No old box/scalar solve or cache-derived report is a fallback.

Old found/cache/averaged-point reporting is removed from the staged World. After all passes, a fresh B query builds Contact.points. The only stage-only B transform is an additional export of the copied module's existing exact native interval primitives. It returns actual represented-line A exit and B entry witnesses plus signedGapM=(Bentry-Aexit)*length(normal). It does not use sampled projection depth as gap, clamp penetration, invoke Python or alter qualified B files. Exact interval-to-float conversion and normal length are independently checked at the frozen 1e-12 m gate.

Constructor geometry is queried under its own trace owner. It initializes accepted contact membership but no persistent impulse cache. Initial events[] and pairWrenches[] are explicit. Subsequent begin/stay/end depends on accepted end-pose geometry only; a transient wrench does not create a contact. The new state can have a wrench without a final contact or a contact without a wrench.

Canonical staged Contact has only collider/body owners and points. Canonical PhysicsState has schemaVersion2 and mandatory pairWrenches. Both geometry and wrench output are copied before the assignment-only state/cache/log/trace commit. Rejected attempts retain all prior accepted fields, active membership, wrenches, cache, trace cursor and recording. The geometry helper's typed refusal occurs before commit.

Staged recorder version is 2 and wire magic is BCPHREC2 only. Exact state/contact/point/body-wrench fields, deterministic pair/point ordering, finite numbers and collider owners are validated before restore creates a World. Old version, old magic, missing schema/wrenches and old flat contact keys are refused without creating a World. No default [] or compatibility decoder exists. Pure private wire-codec exports permit bounded encoding tests without the public serializer's hidden restore; valid public restore still uses the one planned hidden World.

The observer sums each side's actual application vector and world-origin moment independently. It checks both six-component producer wrenches, actual reciprocity, physical cube momentum/spin/midpoint work/passivity, query-owned projection, accepted Contact.points and signed native gaps, accepted membership events, cache/frame provenance, rollback and exact retry/restore. It uses no producer return as an expected sum. Only diagnostic world/attempt/query IDs and generated query pair.id are removed for trace replay comparison; physical words and native correspondence remain.

Evidence encoding is lossless compact JSON, not pretty JSON. Each attempt packet replaces only repeated immutable JSON subtrees of at least 256 bytes with SHA256 references. Every binary64 word, event, before/after pose, cache field and failed-attempt prefix remains in the canonical decoded value. Each packet is self-contained; the independent Python decoder resolves every reference, verifies its full canonical SHA256, rejects cycles/missing/unreferenced nodes, and checks expanded byte accounting before the physical observer reads it. Stored file bytes and expanded canonical bytes are distinct; no compressed size is claimed as an uncompressed bound. The unchanged 16 MiB evidence guard counts actual stored bytes and retains the 64 KiB terminal reserve.

Accepted geometry population is checked completely against every constructor/final B query: pair ownership, all point IDs, every anchor and every normal must be retained exactly; a final MISS has no accepted Contact. Endpoint words are independently rounded from the actual represented-line exits. Signed gap preserves strict sign for independently normal magnitudes and uses the exact squared gap D=(Bentry-Aexit)^2*(normal dot normal). For D>=2^-2044 the additional dimensionless gate abs(reportedGap^2/D-1)<=1e-12 verifies its function as well as its absolute 1e-12 m accuracy. D==0 requires true zero. Nonzero subnormal magnitudes are explicitly NOT_QUALIFIED/refused; no rounding-cell or underflow PASS is inferred. This prevents a factor-of-two tiny gap or a tolerance-sized penetration from being hidden by the absolute tolerance.

Independent decoding is bounded to 16 MiB expanded canonical bytes per packet, 8192 shared nodes, depth 64 and 1000000 canonical fragments. Hashing streams expanded canonical fragments and checks the bound. These are explicit decoding guards; actual stored bytes and expanded bytes are reported separately. No physical data are dropped to meet a cap.

The same unknown marker now fires only after the first nonzero addPairContribution has actually mutated the new candidate pair map. An observational diagnostic record captures that actual bucket before the throw. No unknown fault fires inside apply before its contribution returns. This exercises rollback of the new candidate report as well as candidate bodies/cache, without using that diagnostic bucket as an observer oracle. Known refusal remains before application; attempts/World counts do not increase.

Recording rejection controls test each removed flat Contact key separately, plus old version, old magic, missing schema/wrenches and missing points, all before a World factory call. Initial point-vector mutation isolation and accepted-state/wrench-vector isolation have separate execution labels. A complete failed-attempt prefix is also saved on a constructor/restore/harness exception when available, within the unchanged evidence cap.
