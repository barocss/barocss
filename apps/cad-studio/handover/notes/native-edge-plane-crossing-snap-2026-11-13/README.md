The mesh producer certifies one unmerged native prism edge. The clamped degree-one curve must have two finite equal positive weights. Its ordered poles, native vertices and display endpoints must match exactly. The Model requires opposite signed distances beyond the existing 0.001 mm plane band and bounds the interpolation error at the current coordinate scale. It checks the finite segment, native residual and sketch-frame round trip to 1e-7 mm. The marker and click use the same existing 0.0001 mm local placement. The candidate follows the current accepted root geometry, visibility and plane. Existing candidates win exact screen-distance ties.
