Objects

    Drag a shape to move it. Drag empty space to pan. Use the mouse wheel or zoom buttons to zoom.

    Frames clip their children. Orange overlaps blue. The violet card rotates inside the second frame.

    The first frame shows an even-odd fill with a hole and an island. The second frame shows a self-crossing fill. Drag a path handle to change a curve.

    RGBA quadrants and a rotated cropped checker use host-provided image bytes. Scene JSON saves their IDs, not the bytes.

    The HI glyph run uses a host-provided RGBA atlas. The scene stores text, glyph ranges, and atlas ID.

    Move a selected node or drag it, then use Undo and Redo. Save writes the accepted scene. Open starts a new history.

    Shift-click objects to select more than one. Use the snap toggle, resize and rotation controls, arrow keys, Delete, and Ctrl/Cmd+Z to edit.
