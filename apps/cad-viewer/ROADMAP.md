# CAD Viewer 로드맵

기준: 2026-10-27, 로컬 커밋 `de13200d74af745cf23354d58759b8088ecb2da9`.
이 문서는 구현 순서를 정한다. 일정과 출시 완료를 뜻하지 않는다.

## 목표와 제품 경계

CAD Viewer는 모델을 열고, 탐색하고, 검사하고, 리뷰 결과를 전달하는 앱이다.
CAD 원본을 편집하는 작업은 Studio가 맡는다. Viewer SDK는 표시와 검사 기능을
제공하며, Viewer 앱은 그 기능을 사용자 화면과 작업 흐름으로 연결한다.

화면은 Studio와 같은 React·shadcn/ui 기반을 유지한다. 자주 쓰는 조작은
아이콘으로 표시하고, 아이콘에 접근 가능한 이름과 툴팁을 제공한다.
설명이 필요한 오류와 값은 남긴다. 반복되는 설명 레이어는 추가하지 않는다.

## 현재 상태

| 영역 | 현재 사용 가능한 기능 | 현재 경계 |
|---|---|---|
| 파일 | CAD 문서·조립품 JSON, 제한된 IGES Curve·Surface 입력, 샘플, 표시 대상 선택 | JSON 2 MiB, IGES 1 MiB. 한 장면에 바디 또는 인스턴스 1~4개. STEP·STL 직접 열기 없음 |
| 탐색 | 트리, 검색, 선택, 표시·숨김·격리, 화면 맞춤, 회전·이동·확대 | 화면 선택은 표시 형상에 대한 근사 결과 |
| 검사 | 원본 Curve/Surface 점, Curve 길이·Surface 면적 추정, 문서 점 간 거리 | 길이·면적 오차는 추정치. 문서 거리는 같은 asset 내 두 점만 지원 |
| 조립품 | 계층과 배치, 원본 점의 부품·조립 좌표와 인스턴스 간 직선거리, 거리 리뷰 저장·복원 | 재질 변경은 지원하지 않음 |
| 리뷰 | 이름 있는 뷰, 거리와 조명을 포함한 리뷰 저장·복원, 일반 PNG와 측정 표시 PNG | 리뷰는 원본 파일을 포함하지 않음. PNG의 측정점 투영은 가림 여부를 검사하지 않음 |
| 실행 | 소스 기반 React 앱과 공개 Viewer SDK | WebGPU 필요. 로컬 검증 결과를 배포나 모든 환경 지원으로 보지 않음 |

기능별 세부 조건은 [앱 README](README.md)와
[SDK README](../../packages/barocss-viewer/README.md)에 있다.

## 실행 순서

번호는 실행 순서다. 각 항목의 상태는 **대기**, **자료 대기**, **진행 중**, **완료**로 기록한다.
의존성이나 실제 사용자 파일이 필요한 항목은 조건이 갖춰진 뒤 진행한다.

### 1. 리뷰 결과 전달 — 완료

**목표:** 사용자가 측정한 화면을 그대로 저장하고 다시 확인한다.

- **1.1 [완료] 측정 표시 이미지 내보내기:** 거리 선, A/B 마커, 값과 단위를 포함하는 이미지 내보내기를 추가한다.
  표시 포함 여부를 선택할 수 있게 한다. 기존 viewport 전용 PNG도 제공한다.
- **1.2 [완료] 표시 위치와 투영 검증:** 화면 크기와 픽셀 비율이 달라도 표시와 내보낸 위치가 맞도록 한다.
  화면 밖 점과 가려진 점은 기존 투영 의미를 유지한다.
- **1.3 [완료] 리뷰 불일치 처리:** 리뷰를 열 때 필요한 원본과 현재 표시 대상이 다르면 원인을 보여 주고,
  현재 장면을 유지한다. 완료한 거리와 저장 뷰의 복원을 확인한다.
- **1.4 [완료] 리뷰 전달 흐름 검증:** 실제 브라우저에서 화면과 저장 이미지를 비교하고, 리뷰 저장·복원 흐름을 검증한다.

**완료 기준:** 원본을 열고 두 점을 측정한 뒤, 표시가 포함된 PNG와 리뷰를
저장할 수 있다. 리뷰를 다시 열면 카메라와 거리 값이 복원된다. 오류가 나도
기존 장면과 원본은 유지된다.

### 2. 파일 열기와 탐색 완성 — 진행 중

**목표:** 지원 범위 안에서 파일을 열고 원하는 형상을 빠르게 찾는다.

- **2.1 [완료] 파일 선택과 표시 대상:** 파일 선택, 취소, 재시도와 거부 사유를 명확히 한다. 가능한 경우 항목의
  미표시 이유와 표시 대상 변경 방법을 트리에서 바로 확인하게 한다.
- **2.2 [완료] 키보드 접근성:** 검색, 선택, 숨김·격리, 선택 항목 맞춤과 단축키의 키보드 접근성을 점검한다.
- **2.3 [완료] 작은 화면:** 작은 화면에서도 트리, 뷰포트, 검사 도구를 사용할 수 있게 조정한다.
- **2.4 [완료] 실패와 취소:** 취소·잘못된 파일·입장 실패가 이전 장면과 리뷰를 보존하는지 확인한다.
- **2.5 [자료 대기] 실제 사용자 파일:** 실제 사용자 파일이 확보되면 그 파일로 열기부터 검사까지 검증한다.
  샘플이나 테스트 fixture 결과는 실제 사용자 파일 검증과 따로 기록한다.

**완료 기준:** 지원 파일에서 원하는 바디를 찾아 검사할 수 있다. 실패와
취소는 이전 장면을 보존한다. 마우스와 키보드의 주요 경로를 확인한다.

### 3. 조립품 검사 — 완료

**목표:** 조립품의 배치를 기준으로 서로 다른 인스턴스를 비교한다.

- **3.1 [완료] 조립품 점 선택:** 부품 원본 좌표와 조립품 좌표를 구분해 A/B를 선택한다.
- **3.2 [완료] 인스턴스 간 거리:** 서로 다른 인스턴스의 두 점을 조립 좌표로 평가하고 직선 거리를 표시한다.
- **3.3 [완료] 인스턴스 결속 검증:** 인스턴스 경로, 원본 reference, 배치와 revision을 검증한다. 배치가 다른
  동일 부품의 두 인스턴스를 구분한다.
- **3.4 [완료] 조립품 리뷰 검증:** 거리의 저장·복원과 실패 시 기존 장면 보존을 검증한다.

**의존성:** 문서 거리 API는 조립품에 사용할 수 없다. 조립품 거리는 SDK가
각 원본 점과 배치를 다시 평가한다. 리뷰 복원에는 별도의 원본 결속과 검증이 필요하다.

**완료 기준:** 서로 다른 배치를 가진 인스턴스 두 개에서 기대 조립 좌표와
거리를 검증하고, 저장한 리뷰를 동일 조립품에서 복원한다.

### 4. 더 큰 모델과 안정성 — 진행 중

**목표:** 지원 범위를 측정하고, 그 범위를 안전하게 넓힌다.

- **4.1 [완료] 표시 한도와 대상 교체:** 4개 표시 한도의 원인과 CAD·GPU·Viewer의 각 예산을 확인한다.
  우선 많은 항목 중 필요한 항목을 교체하는 흐름을 개선한다.
- **4.2 [진행 중] 한도 확장과 성능 측정:** 한도 확장이 가능하면 의존 패키지의 공개 계약과 함께 단계적으로 적용한다.
  바디 수, 메모리, 열기 시간, 선택과 화면 응답을 같은 조건에서 기록한다.
  현재 한 asset의 원본 객체 최대 16개를 CPU와 브라우저에서 확인했다.
  동시 표시 4개는 유지한다. 브라우저 선택·카메라 입력부터 두 번째 rAF까지의
  렌더 기회 대리값을 측정했다. GPU 시간·메모리와 동시 표시 한도 확대는 남아 있다.
- **4.3 [진행 중] 장치와 리소스 오류:** WebGPU 미지원, 장치 손실, 캔버스 크기와 리소스 부족의 사용자 경험을 정한다.
  격리된 브라우저에서 실제 GPUDevice를 강제로 종료한 뒤 장치 재생성, 픽셀과
  상태 복원을 확인했다. 자연적인 하드웨어 고장과 여러 장치의 복구는 검증하지 않았다.
  WebGPU 부재 화면은 시뮬레이션으로 확인했다.
  재생성 요청 거부를 주입하면 원본·리뷰는 유지되지만 실패 원인은 콘솔에만 남는다.
  장치 생성 후 컨텍스트 획득 실패를 주입하면 오류 화면은 표시되지만, 1초 관찰 중
  생성된 장치의 명시적 종료는 확인되지 않았다. GPU 초기화 정리가 필요하다.
- **4.4 [자료 대기] 반복 사용 검증:** 정해진 브라우저와 장치에서 실제 파일을 반복해 열고 닫는 검사를 수행한다.
  파일 닫기와 지연 작업 무효화를 구현했다. 문서·조립품·IGES fixture의 닫기와
  재열기를 브라우저에서 확인했다. 실제 사용자 파일의 반복 검증은 남아 있다.

**완료 기준:** 지원 데이터 크기와 환경, 측정 조건, 거부 및 복구 동작이
문서화된다. 한도 변경은 SDK·GPU와 실제 브라우저의 근거가 있어야 한다.

### 5. 형식과 고급 리뷰 기능 확장 — 진행 중

**목표:** 검증된 원본과 표시 경로가 준비된 기능부터 확대한다.

- **5.1 [진행 중] 추가 파일 형식:** STEP·IGES·STL 등은 CAD/변환 경로의 실제 지원, 단위·배치·원본 식별자 및
  오차 계약을 확인한 뒤 형식별로 추가한다. 형식 이름만 보고 지원을 선언하지 않는다.
  IGES는 writer 호환 ASCII 126/128, mm·scale 1 경로를 브라우저에서 확인했다.
  일반 IGES와 원래 ID·조립 구조는 지원하지 않는다.
- **5.2 [대기] 단면·주석·비교:** 단면, 주석, 비교 등은 실제 사용 흐름과 하위 API를 확인해 별도 작업으로 정한다.
  화면 절단과 원본 CAD 단면의 의미를 구분한다. 첫 화면 절단 범위는
  [계약 문서](SECTIONING.md)에 정리했다. 현재 기능은 미구현이다.
- **5.3 [대기] 서버 공유:** 다른 사용자와 공유하는 서버 기능은 저장소·인증·권한의 제품 요구가 정해지면 설계한다.

**완료 기준:** 각 기능마다 실제 입력, 예상 결과, 의존 API와 실패 처리를
정하고 브라우저에서 확인한다. 표시 근사 결과를 인증된 CAD 결과로 표현하지 않는다.

## 공통 완료 기준

각 작업은 작은 사용자 흐름 단위로 끝낸다. 관련 타입 검사와 필요한 동작 검사를
실행한다. 화면 변경은 실제 브라우저 이미지와 조작 결과를 남긴다. 원본 보존,
저장·복원과 실패 시 이전 상태 보존이 관련되면 함께 확인한다. 테스트 fixture,
실제 사용자 파일, 브라우저와 GPU 검증은 구분해 보고한다.

멀티 에이전트는 서로 다른 파일 또는 읽기 전용 검토를 맡는다. 통합은 한 곳에서
수행한다. 각 작업의 결과와 다음 작업을 보고하고 계속 진행한다.

**완료:** 1.1 측정 표시 이미지 내보내기. 실제 브라우저에서 8 mm 측정 PNG와
일반 PNG를 저장해 확인했다. 1.2에서는 픽셀 비율 1과 2, 두 점이 화면 밖인
경우를 확인했다. 투영은 가려짐을 검사하지 않는다. 1.3에서는 원본과 표시 대상의
불일치를 구분하고, 거부 시 기존 장면과 저장 뷰가 유지되는 것을 확인했다.
1.4에서는 실제 화면에서 원본 점을 측정하고 PNG와 리뷰를 저장한 뒤,
화면을 변경하고 저장한 리뷰를 다시 열어 복원했다.
2.1에서는 미표시 항목에서 선택 화면을 열고, 표시 한도·취소·재시도와
입장 실패 시 기존 장면 보존을 확인했다. 2.2에서는 키보드 카메라 조작,
검색·선택·표시·격리·맞춤과 저장 뷰의 포커스를 확인했다. 2.3에서는 작은
화면의 패널 전환, 원본 점 측정과 리뷰 저장·복원을 확인했다. 2.4에서는
작은 화면의 취소, 잘못된 JSON, 입장 실패와 재시도를 확인했다. 운영체제 파일
선택창의 실제 취소는 이 검증에 포함하지 않았다. 유효한 파일 읽기를 지연한 뒤
후보 취소, 파일 닫기, 다른 문서 입장에 이어 늦게 완료해도 현재 상태를 덮지
않는 것을 격리 브라우저에서 확인했다. 읽기 지연은 시험에서 주입했다.

3.1과 3.2에서는 서로 다른 인스턴스의 두 원본 점과 조립 좌표 거리를 확인했다.
조립품 거리의 저장·복원을 브라우저에서 확인했다. 잘못된 새 점 검사에도
기존 거리를 유지하며 저장하는 수정은 앱 테스트와 브라우저에서 확인했다.

3.3에서는 저장소 fixture의 경로와 배치, revision 교체와 오래된 참조 거부를
검사했다. 앱의 무효화 검사는 실제 Viewer와 상태 복사본을 사용했다.

4.1에서는 네 개가 표시 중일 때 기존 항목 하나를 직접 골라 교체하고,
취소 시 기존 장면을 유지하는 동작을 브라우저에서 확인했다.

**현재 작업:** 2.5와 4.4는 실제 사용자 파일을 기다린다. 4.2는 동시 표시
확대 계약을, 4.3은 복구 실패 전달 계약, 자연 장치 손실 검증과 GPU 초기화 정리를 기다린다.
5.1은 일반 IGES와 STEP·STL의 추가 계약을 기다린다.
