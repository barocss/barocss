# Current qualified native Shell leaves

This bounded host shows explicitly selected current normal-extrusion graph
leaves through public `loadShellGraph`. It reads original authored graph files,
parses/rebuilds them through public CAD, and lets Viewer derive exact native
meshes through the existing interop wrapper. It does not submit cached meshes,
fake primitive packets, rewritten sources or baked geometry.

The source menu includes committed fanout three-leaf, edited-distance and
genuine-empty graphs, plus committed feature-mesh revision1/revision3 graphs.
Readonly CAD903 containment-hole/two-component and CAD927 fourth-leaf files
are optional authentic controls. Their exact paths, original byte counts and
SHA256 hashes appear in `/fixture-manifest.json`. Browser startup fetches and
checks those unchanged bytes before public parsing with graph options8/7.
Raw bytes/text remain available separately from evaluated native authority.

Use Node22. Ordinary development resolves public package names through their
normal source-default exports, without aliases or custom conditions:

```sh
node examples/viewer-shell-scene/server.mjs
```

Open <http://127.0.0.1:52999/>. Show checkboxes submit an explicit current leaf
list; they do not invoke unsupported primitive visibility/picking methods.
Show all leaves, Clear viewer, Fit leaves, Turn view and Pan view are physical
DOM controls. Holes and components retain native provenance. Zero selected
entries and genuinely empty selected leaves have distinct copied states.
Inspect mode queries current filled Shell leaves. Face editing, material authoring and playback are unavailable.

After building providers and Viewer, the required explicit compiled checkpoint
resolves every transitive own public entry/subpath through the complete
`publishConfig.exports.import` map:

```sh
VIEWER_SHELL_COMPILED=1 node examples/viewer-shell-scene/server.mjs
```

The server bundles once and prints an audit summary. `/input-audit.json`
requires own src with zero own dist in ordinary mode, and own dist with zero
own src in compiled mode. Missing compiled mappings refuse; no manifest or
development condition is changed. `VIEWER_SHELL_PORT` sets the port and
`VIEWER_SHELL_EVIDENCE` optionally records the bounded `/result` JSON.

Default readonly saved controls are:

- `/Users/user/.barocss-ai/v3/evidence-903-cad/integration/demo-output/{containment_hole,strip_two_components}.authored-graph.json`
- `/Users/user/.barocss-ai/v3/evidence-927-cad/integration/demo-output/fourth_literal_extrusion_leaf.authored-graph.json`

Set `VIEWER_SHELL_CONTROL_DIR` or `VIEWER_SHELL_FOURTH_FILE` to exact original
files elsewhere. Unavailable optional controls are disclosed and omitted;
committed required fixtures must exist. Only authored graph files are read.
The server also serves original assembly revision0/1 and original979 native
panel source for separate transition controls. `/slow-native.barocad` holds
an HTTP native source response until `/release-slow` receives POST, allowing
the main acceptance runner to check actual request supersession without a
network race based on guessed timing.

Run proof records native qualification/source copies and actual converted GL
uploads, exact ref/options/report/getter/budget/allocation refusals, camera
retention, an independent fixed overlap ray against native cap triangles,
near/far/full forward/reverse depth controls, edited/four/hole/strip fixtures,
genuine empty versus zero entries, primitive/Shell transitions and Clear.
Edges remain optional previews with no certified hidden-line claim. A first
failure remains recorded with completed cases and accepted page state.

`window.__viewerShellProof` exposes public Viewer/gl/copied state, original
graphs/text/bytes, parsed fixture map, reference and entry helpers, public
CAD graph parse/evaluate/update, public Assembly/Model-set Loader, public
Physics cloth creation, original panel source, public GPU constructors,
actual buffer readback, seven global resource counters/peaks and allocation
fault controls. `runProof()` stores/posts `__viewerShellResult`; `dispose()`
is a separate idempotent cleanup stage. Counters cover temporary overlapping
old/candidate renderers, rather than one backend's local counts.

The main runner owns the complete browser acceptance, including actual hole
and disconnected-component pixel witnesses, prior cloth/assembly transitions,
held URL races, extra exact-input cases, separate actual context loss and
normal disposal resources0. Lost-context deletion counters0 are not claimed.
Source/build/assertion existence, actual execution, native completion,
Integration and publication remain separate evidence stages.


## Inspect current filled Shell leaves

Enable **Inspect mode**, then click the canvas. The host marks the current original graph/feature/output-slot row and shows approximate display depth. GPU colors and Viewer selection stay unchanged. This result describes the lowered filled triangle preview; it does not certify a native face hit, edge pixel, topology or hidden-line result. Ambiguous leaves use the documented global-depth tolerance and deterministic full-reference ordering.

A successful source/view/backing/CSS change clears inspection. A failed candidate retains the accepted row. Empty selection and genuine empty leaves give no hit. Lost/unavailable/disposed presentation refuses inspection; CPU provenance remains separately readable after loss. The host canvas is borderless and axis-aligned so click coordinates use its bounding box. Source and all-transitive compiled verification are separate checkpoints.
