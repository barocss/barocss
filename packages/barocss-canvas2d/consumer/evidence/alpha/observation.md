# Scene v10 inherited alpha: native consumer observation

This is one fixed local Node 22.22.0 and headed Chromium 155/WebGL2 run on the independent `@barocss/canvas2d` compiled entries. The native branch starts from the exact separately verified #867 local `develop` merge `d2ca0727`. The library build produced a 149.6 KiB ESM entry. Strict package-local consumer TypeScript checking passed. All 39 Canvas2D Node probes passed, including the new Scene v10 alpha probe: seven public handle kinds, finite `[0,1]` refusal/atomic rollback, strict old Scene v6–v9 shapes, v10 missing/extra fields, zero-alpha pointer refusal and v1 document/owned asset bytes. The alpha probe's separate document was 2,106 bytes.

The main compiled consumer used a 100 × 80 logical-pixel canvas at DPR 2, a gray Back, a blue Frame with a red 1 × 1 RGBA8 Sprite and green Vector under one Parent. With Parent alpha 1, the Sprite, Vector and Frame samples were exact red `[255,0,0,255]`, green `[0,255,0,255]` and blue `[0,0,255,255]`. At Parent alpha 0.5, those same samples were `[143,16,80,255]`, `[16,143,80,255]` and `[32,32,159,255]`, with unchanged `Sprite`, `Vector` and `Frame` hit IDs. A real pointerdown at the Sprite delivered `Sprite → Frame → Parent → stage`. At Parent alpha 0, all three samples became gray `[64,64,64,255]` and hit `Back`; the next real pointerdown delivered `Back → stage`. Invalid negative-zero alpha returned `INVALID_SCENE`; missing and out-of-range assets inside the zero-alpha subtree each returned `INVALID_ASSET`. The accepted pixels and hits stayed unchanged after each refusal.

For nested multiplication, Parent alpha 0.5 and Sprite alpha 0.5 produced `[88,24,119,255]` at the Sprite point while retaining its hit and authored Sprite opacity 1. The browser downloaded the actual [1,425-byte v1 document](document.json). After page reload, its file chooser opened that file on a fresh canvas, renderer and tree. The saved alpha values, all four RGBA8 asset bytes, pixels and hit IDs matched. Editing the restored Parent to alpha 1 changed the Sprite sample to `[128,0,128,255]`; a new pointerdown again delivered `Sprite → Frame → Parent → stage`. Screenshots show the [restored edit](reopened-edited.png), [half-alpha state](half.png) and [zero-alpha state](zero.png).

A second compiled browser flow used an owned Red, Green and White 1 × 1 asset, a nested Parent × Frame alpha of 0.25, a path fill/stroke, finite line, glyph-run opacity 0.8, additive Sprite opacity 0.8 and a later independent normal Sprite. At alpha 0.25, samples/hits were Path fill `[102,51,51,255]`/`Path`, path stroke `[82,92,41,255]`/`Path`, Line `[51,102,51,255]`/`Line`, Glyph `[102,102,102,255]`/`Glyph`, additive image `[115,64,64,255]`/`Add`, and following normal image `[0,255,0,255]`/`Normal`. Setting Parent alpha to 0 changed the first five samples to gray `[64,64,64,255]`/`Back`; the independent normal image stayed green/`Normal`. The page console showed zero errors and warnings.

Local `npm pack` produced a 94,931-byte archive. A repository-external temporary consumer installed that file with offline and no-scripts flags, ran both public ESM entries with a v10 alpha/document round trip, and passed strict TypeScript declaration checking. The first offline install attempt used the host's shared npm cache and stopped with a cache ownership error (exit 243); a second attempt with a fresh consumer-local npm cache passed. Neither command contacted a registry or published a package.

The first build command used the worktree without the shared root `tsc` bin on `PATH` and stopped with `tsc: command not found`. Re-running with the installed Node 22 and root bin passed. The first broad probe pass found a v10 fixture migration error in an older rectangle probe; legacy test fixtures were corrected to remove alpha from pre-v10 Scenes and add it to authored v10 nodes. The final 39/39 pass is recorded above. This evidence is one bounded browser and document run, not a broad device, color-space, performance or release result.
