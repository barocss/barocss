# D345 검증 결과

직선 다각형 구멍을 가진 Fill CUT 마스크를 Kernel·공유 API·Model·실제 Studio에 연결했다. 기존 총16개 꼭짓점 한도를 유지한다. 추가 컷의 기준점이 구멍 안이나 경계에 있으면 제외한다. 원래 컷과 격자 이름은 유지한다. 도구 전체를 잘라내거나 경계 안에 넣는 기능은 아니다.

커널 신규9개와 관련22개, Model 신규6개와 관련87개가 통과했다. 타입·영향 범위 lint·API·생성 문서 검사와 Studio 빌드·chat23개도 통과했다. API 변경은 기존 타입의 optional readonly holes 필드 하나이며, 세 공개 경로에 반영했다.

실제 Chrome 하나에서 문맥4개를 순서대로 실행했다. 관찰15건, native 읽기8건, 독립 Fraction 검증6건, 실제 저장2건과 새 문맥 열기를 마쳤다. 적용7개→간격 변경9개→원본 편집 뒤 명시적 재선택5개를 확인했다. Undo/Redo, 저장된 이름·ID·구멍 좌표·컷 꼭짓점·닫힌 형상·비교용420부피 객체를 확인했다. 화면6장을 별도로 검토했다. 화면의 반올림 값은 질량 수치의 근거로 쓰지 않았다.

첫 실행은 단위를 포함한 label 탐색 오류였다. 두 번째 실행에서는 실제 제품의 선택 오류를 확인했다. Fill이 본체를 교체한 뒤 이전 번호가 비교용 객체를 선택했다. 성공한 Fill 적용에만 선택 해제를 추가했다. Cancel과 거절은 기존 선택을 유지한다. 두 실패 기록을 보존하고, 수정 뒤 세 번째 전체 흐름이 통과했다.

원본 스케치 편집은 구멍을 유지한 바깥 경계 편집이다. 저장된 구멍 좌표를 UI에서 직접 숫자로 편집했다는 뜻은 아니다. 원본 편집만으로 기존 스냅샷은 바뀌지 않으며, 명시적 재선택 때 갱신한다. 구조적 작업 한도는 처리량 측정치가 아니다.

이번 변경의 전체 Kernel·전체 Model·전체 Studio 테스트, 성능 측정, 원격 CI는 실행하지 않았다. 영향받는 검사를 사용했다. 08 전체 완료, 곡선 마스크·임의 프레임·도구 전체 포함·일반 선택 재매핑·release는 범위 밖이다. [상태 기록](qualification.json)과 [원본 증거 목록](artifact-manifest.json)을 함께 본다.

첫 문서 검사 명령은 Node22 PATH 설정을 빠뜨려 기본 Node18.10.0에서 실패했다. 원본 오류 로그를 보존하고 지정된 Node22로 다시 검사했다. 제품 코드 오류와 구분한다.
