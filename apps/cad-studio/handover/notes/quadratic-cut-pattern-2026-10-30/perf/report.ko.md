# D346 계산량 개선 측정

상태: 기준 측정 완료, 후보 비교 대기. 기준은 게시된 D345가 아닌 D346 개발 중의 고정된 빌드다. 원본 소스와 dist 및 해시를 baseline/에 보존했다.

지정된 perf-bench.mjs에 실제 3개 CUT 결과를 만드는 고정 사례 2개를 추가했다. 기존 runner와 형상 비교 공차는 바꾸지 않았다. Node22.19.0, 준비3회, 측정7회, batch1, 동일 입력, 단독 heavy 조건이다. 입력 문서 생성은 타이머 밖이며 실제 feature 평가와 native CUT 처리는 안에 있다. 순수 planner 시간이나 Studio 입력 지연이 아니다.

기준 중앙값은 곡선3CUT 5.135833ms, 기존 직선3CUT 2.591125ms다. 두 결과는 strict 유효성, 본체1개, 면18개, 선48개, 꼭짓점32개, 부피23550을 확인했다. 이름과 질량 중심도 원본 JSON으로 보존했다. 해시는 형상 정답이 아니며, 별도 위치·부피 검증을 대신하지 않는다.

64개 요청은 기준 구현에서 연산 한도 거절이다. 이 입력에는 승인된 전후 형상 비교를 주장하지 않는다. 후보에서 동일 한도로 성공하는지 확인하고, 이미 성공한 3CUT 사례의 전후 형상과 시간을 비교할 예정이다. 7개 표본의 한 쌍으로 일반적인 속도나 회귀를 단정하지 않는다.

## 후보 비교

- quadratic-path-cut-3: 5.135833 → 4.430542ms (-13.73%). 비트 동일 False; 형상 비교 SAME, 부피 23550 → 23550.
- straight-path-cut-3: 2.591125 → 2.506709ms (-3.26%). 비트 동일 True; 형상 비교 SAME, 부피 23550 → 23550.

곡선의 비트 차이는 배치 후보 선택이 달라진 결과다. 독립 위치 오차 검사와 native 꼭짓점 검사를 별도로 통과했으며, 유효성·개수·이름·부피·질량 중심의 전후 조건을 만족한다. 직선 비트와 기존15배치/거절 값은 유지했다. 이7표본은 관찰값이며 일반적인 속도 향상이나 회귀를 단정하지 않는다. 공개64요청은 최초200k 거절에서 최종196882/200000으로 성공했다. 형상 승인 전후가 존재하는 성능 비교는3CUT 사례뿐이다.
