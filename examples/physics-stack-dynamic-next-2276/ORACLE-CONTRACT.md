## Wire and returned interface

One JSONL line is `{format:'dynamic-next-case-v1',data:{caseId,model,options,states:[initial,...actual public states]},numericWordsF64leHex}`. Sidecar order is every numeric leaf of **data only**, in JavaScript Object.keys/array order, IEEE F64 little endian, lowercase16hex per word. It includes model/options, complete public states, clocks/counters and signed zeros. It excludes the envelope and sidecar itself. Restore requires finite JS Number agreement, restores zero sign and consumes exactly all words. A nonzero mismatch, missing/trailing/nonfinite word, duplicate JSON key, malformed type or absent word refuses. Boolean is not a Number. Numeric counts restored as Python floats are accepted only when integer-valued and bounded; there is no unconditional Python-int test.

The per-line limit remains **2MiB including newline**. Cumulative input per process is at most16MiB and8 requests; depth32/nodes262144/numeric words262144 are bounded. Whole-case refusal is retained if the actual complete case exceeds a bound; there is no truncation, cap rise or chunk rewrite after seeing the result. Replies are finite JSON under64KiB. These wire bounds do not certify global memory or RSS. The runner separately owns per-graph16MiB evidence,48Worlds/1024 actual accepted steps, and all restore/control counts. This oracle never invents World/solver/restore calls from state population.

Exports: `restore_words(value, hex)`, `verify(data)`, `convergence(replies)`. `verify` returns serializable `{ok,resolved,executionFailure,status,violations,metrics,certificates}`. A physical gate failure is resolved with ok=false; malformed/unsupported data has executionFailure=true/resolved=false. Violations are bounded to32, with actual step context when available. Out-of-binary64 diagnostic magnitudes are explicit strings, never0 or Infinity. CLI reads lines and emits one reply each. A separate optional envelope `{format:'dynamic-next-convergence-v1',replies:[actual60reply,actual120reply,actual240reply]}` checks returned ratios; it has no candidate calls and no simulated state. The present runner may instead compare both returned scalar errors itself without copying reference equations.

## Fixed actual inputs and populations

All five cases use the existing `rigid-persistent-box-v1`/direct public path. Cube half-extents are `[.5,.5,.5]`, mass2kg, primitive-COM inertia (`I=m/6` per axis), identity initial orientation and spin0, friction0, no commands/sensors/filtering/CCD/sleep/joints/other domains/source bindings. Each model body has exactly one identity-local box collider. Unknown profiles/populations refuse.

- `ballistic-60`, `ballistic-120`, `ballistic-240`: one isolated cube at `[0,10,0]`, rest, g=`[0,-9.81,0]`, e0, h=represented JS Number1/hz, exactly hz transitions to one nominal second. There is no floor or contact.
- `gravity-fall`: one dynamic cube at Y.75/rest, static floor at Y-.5 with half-extents `[2,.5,2]` and top0, g=-9.81, both e0, h=1/120,256 transitions. First actual contact must be later than step1; afterward the e0 cube is supported at the floor within the original gates.
- `delayed-pair`: two dynamic cubes, lowerY-.5/rest and upperY.625/vY-2, g0, e materials.25 and.8, h=1/120,256 transitions. One later contact, then relative separation/free motion. No floor and no second simultaneous pair are admitted.

Exactly initial+all fixed transitions must be supplied. Every clock/step is contiguous, identity remains the same, body/collider links are complete and static body words remain exact. Candidate-supported spin/rotation is not claimed: outputs are checked against zero spin/identity/lateral motion at the same1e-10 scale. These are centered one-dimensional specimens, not a general rotating or coupled contact oracle.

## Independent equations and unchanged gates

Noncontact checks use Fraction values decoded from the actual binary64 input. At constant acceleration, the reference evaluates the closed forms `v_n=v0+g*n*h`, `p_n=p0+n*h*v0+g*h²*n(n+1)/2`; it does not call or reproduce the candidate's iterative contact update. Separately it evaluates continuous `p(t)=p0+t*v0+g*t²/2`, `v(t)=v0+g*t`, where t=n*h for the represented h. It does not require the kick-drift integrator to equal the continuous position.

Existing ballistic gates remain velocity1e-11m/s, continuous position error strictly<.083m, actual position-error ratio[1.99,2.01] across60/120/240. Both returned `metrics.continuousPositionErrorM` and `metrics.continuousEnergyErrorJ` are **absolute actual errors**, and both ratios must satisfy the same interval. The signed actual energy difference and analytic first-order defect are separately returned as `signedContinuousEnergyErrorJ` and `analyticFirstOrderEnergyDefectJ`. Kick-drift's energy defect is `-m*|g|²*T*h/2`. Its agreement is checked within1e-10J. The certificate explicitly says the integrator does not conserve the continuous energy. Closed-form noncontact position residual uses1e-10m; no gate is widened to admit the first-order bias.

Every actual transition reconstructs free linear momentum from BEFORE plus external `m*g*h`, then tests each body's measured `m*(v_after-v_before)` against gravity plus the actual public contact impulse. Normal/tangent impulse signs follow actual A/B links, and body torque uses actual public point/arm and impulse. Because the admitted motion and position correction are vertical, the Y difference between free and corrected COM cannot change the normal torque's X/Z arms. Residual spin/normal/tangent departures remain bounded by the original gates; this is not an extension to off-center motion.

At an actual contact, actual free relative velocity determines closing speed. Newton's normal velocity ratio plus independent linear momentum gives the impulse, with reduced mass and min material restitution only when closing>0.5 exactly; otherwise e0. Kinetic energy loss is `(1-e²)*reducedMass*closing²/2`. The oracle checks measured outgoing relative speed, total public normal impulse, individual body momentum/COM angular momentum, contact kinetic energy loss, lateral motion and final surface gap. It never copies the per-point iterative solve or cache updates. It does not infer an exact pointwise multiplier distribution from a pair aggregate.

Velocity/omega/impulse/body momentum/angular momentum/gap/energy gates remain1e-10 SI; tangent impulse remains1e-12Ns. Negative impulses refuse. A valid positive noncontact gap is not tested as zero. Gravity/projection potential work is reported separately as max and cumulative `-m*g·(p_after-p_free)`; it is not erased from total energy to declare exact conservation. First-contact frames are actual saved states. The pair's continuous gap/closing time is compared with its discrete sample interval. Gravity contact's continuous squared time `2*initialGap/|g|` is compared with the honest h-scale bracket `[(n-1)h,(n+1)h]`, **not** forced into `[actualBeforeTime,actualAfterTime]`: kick-drift can meet the floor earlier than the continuous trajectory. Both the narrower sample interval and continuous time are reported. No exact TOI or remainder integration is claimed.

The reference handles only these fixed finite specimens. Rotating/tilted/off-center frictional impacts, simultaneous multiple pairs, dynamic8, joints and post-TOI remainder remain outside its proof.
