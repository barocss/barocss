## 2. Data model: feature-tree node resolved in the kernel
Model (doc.ts beside thicken ~:420):
```ts
export interface BandSide { parent: BodyRef; edges: string[] }   // kernel edge names, ≤32, pick order
| { kind: 'band-surface'; version: 1; a: BandSide; b: BandSide; flip?: true; thickness?: Dim; side?: 'normal'|'reverse'|'both' }
```
sigs (NodeExtras) keyed by edge name; a name may appear on only one side (else INPUT).
Kernel feature (part-model.ts union ~:265):
```ts
{ kind:'band-surface'; a:{target:string; edges:string[]}; b:{target:string; edges:string[]}; flip?:boolean; thickness?:CadPartDim; side?:'normal'|'reverse'|'both'; expect?:Record<string,CadPartNameSignature> }
```
Targets read with ref() (never consumed: A and B stay bodies). Output: no thickness → one exact sheet body, output id = feature id, one face per patch `${id}.band${k}`, edges `${id}.a|${id}.band${k}`, `${id}.b|${id}.band${k}`, `${id}.band${k}|${id}.band${k+1}`; with thickness → a faceted solid with named facet groups `${id}.outer`, `${id}.inner`, `${id}.end0`, `${id}.end1` (open only). Output carries `band: {pairs, closed, exact:true, boundaryDeviation, chord?}` copied by makeOutput (part-model.ts:2141; Part field :742). Downstream: face colours, measure, mates, names via the same policy; features on the sheet's edges not in v1.

## 3. Geometry (kernel features/band-surface.ts, new, module functions)
1. Resolve each side: every B-rep edge whose name equals a stored name (several pieces allowed). None → SELECTION `[BAND_EDGE_LOST] band side A: no edge named X on n2`. Facet bodies → CAPABILITY `[BAND_PROFILE]`.
2. Chain via shared vertex ids into one simple open chain or one closed loop (a single closed edge counts), ≤32 pieces; branch/gap/two pieces → SELECTION `[BAND_CHAIN]` with the vertex xyz. Orient pieces by exact reverse.
3. Orientation: open↔open keep B's direction giving the smaller sum of the two end-ruling lengths (tie within 1e-9 rel: stored order). closed↔closed: A stored order; orient B so the dot of polyline area vectors is positive; |cos| < 0.1 → SELECTION `[BAND_OBLIQUE]`. closed↔open → `[BAND_CHAIN]`. flip reverses B relative to the default.
4. Pairing: equal piece counts → piece k↔k (closed: B's seam = its vertex nearest A's start vertex). Unequal → split each chain at the union of both chains' normalized cumulative arc-length breakpoints (Gauss quadrature; Newton inverse to 1e-12), merge breakpoints closer than 1e-4 normalized; closed: B's seam = closest point on B to A's start (snap to a vertex within 1e-9). Splits exact.
5. Patches: per pair exact affine reparametrisation to [0,1], elevate to common degree ≤3, buildAlignedRationalRuledSurface. SectionKnotAlignmentError / degree >3 / >16 poles → CAPABILITY `[BAND_PROFILE] pair k: …` (no approximation in v1). Any ruling < 1e-4 mm → GEOMETRY `[BAND_TOUCH]` at xyz. Zero normal at any of 9×3 samples per patch → GEOMETRY `[BAND_DEGENERATE]`.
6. Honest deviation: boundaryDeviation = max over 33 samples per patch of |S(u,0) − A_orig(t(u))| and |S(u,1) − B_orig(t(u))| vs the unmodified source curves. Note: "N exact ruled patches (paired by pieces | by length N↔M); boundary deviation ≤ x mm"; with thickness add "faceted 24×16 per patch; measured chord deviation y mm".
7. Sheet B-rep (new brep/band-sheet.ts): buildBrep with shared ruling edges; closed band shares its seam ruling; must pass checkBrep (open shell).
8. Strip thicken (new brep/thicken-strip.ts): same scheme as thickenSolid with thickenFoldCheck per patch (blend/offset-cavity.ts); shared columns at rulings and the seam use the averaged unit normal (watertight mitre); no u-walls when closed; output via facetBrepFromTriangles with groups; refuses OFFSET_FOLDS and GEOMETRY. Export the existing normal routine from thicken-solid.ts without changing its behaviour.

## 4. Reference policy
| Case | Evaluation | Studio edit/suppress | On Open |
|---|---|---|---|
| Lost (no B-rep edge with the name) | [BAND_EDGE_LOST] | refused with reason | held `"X" is gone` |
| Moved (name on other geometry) | [REFERENCE_MOVED] from expect | refused | held with candidate `"X" could be Y` (strict: no substitution) |
| Ambiguous | — | chat edit: "is now one of …" | held "could be A or B" |
| Structural (names resolve, no single chain) | [BAND_CHAIN] | refused | — |
Parents: a parent at/after the band's index → [BAD_REFERENCE]; a suppressed/gone parent makes the band gone (part.ts:563-566). Known limit (record): expect refuses when an upstream edit moves an edge more than twice as far as another alike edge sits from the old position (e.g. box height ×4); signatures refresh after each accepted edit.
Tests: regeneration (box n1 side-tagged sketch + vertical fillet n2 r3; band A = n2's top loop (8 pieces), B = top rim of cylinder n4; box height 10→14 → A boundary = box top vertices z=14; fillet r 3→5 → arc boundary radius 5; names unchanged); lost face (sketch drops side e3 → [BAND_EDGE_LOST] naming `n1.side[e3]|…`; same doc via verifyReferences holds the band with the reason, box and cylinder build; suppressing n2 refused (toast); deleteFeature(n2) refused "refers to the edge"); no silent retarget (where a fillet's name would be marked re-matched, the band's identical name stays and is held).
