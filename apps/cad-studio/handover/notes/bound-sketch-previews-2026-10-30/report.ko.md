# D357 보고 — 매개변수에 묶인 스케치의 미리보기와 로프트

로드맵 09의 열 번째 한정 항목입니다. D356 감사의 곁가지 메모를 고쳤습니다. 소스 커밋은 `9ba588d0c`입니다. 관련 이슈는 #551과 #2250이고, 둘 다 열어 둡니다.

## 문제

치수가 매개변수 W에 묶인 스케치를 미리보기와 로프트가 NaN으로 읽었습니다.
- 모델 화면의 윤곽선이 깨졌습니다.
- Extrude와 Revolve의 핸들이 NaN 위치에 놓였습니다.
- Loft가 `null` 좌표로 단면 사본을 만들어, 커널이 이를 거절했습니다.

## 수정

- 미리보기, 핸들, Loft가 문서의 매개변수 값으로 치수를 계산합니다.
- 매개변수가 없거나 유한하지 않으면 스케치 이름을 넣은 메시지로 거절합니다. 예: "Sketch 2 uses parameter B, …"
- Loft 단면은 지금 값으로 복사됩니다. 그래서 Loft 단계에 "Sizes — Copied at W = 60: later parameter changes do not update this loft."를 보여 줍니다.
- Bézier 가이드 경로의 동작이 바뀌었습니다. 예전에는 사본이 바인딩을 유지해서, 값을 바꾸면 커널이 크게 실패했습니다. 이제는 다른 경로와 같이 그때 값으로 복사합니다.
- `loftTop`은 묶인 스케치를 받으면 NaN을 쓰지 않고 거절합니다.

## 감사와 실패 기록

독립 Opus 감사 결과는 CHANGES_REQUIRED(작음)였습니다.
- 지적 사항: 스냅샷이 아무 알림 없이 일어남, 가이드 경로 변경이 기록에 없음, 변이 M7–M10이 살아남음, 메시지에 코드 접두어가 붙음.
- 모두 고쳤습니다. 곁가지 메모 S2와 S3도 고쳤고, S1(`loopOf` NaN)은 남아 있습니다.

실제 실행 기록입니다.
- run01: 드라이버 오라클의 타입 오류로 실패했습니다.
- run02: 감사 전 소스에서 PASS였습니다.
- run03: 자동 검사는 PASS였지만, 루트 이미지 검토에서 새 단계 이름 "Parameters"가 본문과 겹쳐 보였습니다. 이름을 "Sizes"로 바꿨습니다.
