# HINGE2 World — 독립 참조와 자료 계약 선택

이 문서는 코드 전 선택이다. 실제 World 계산·build·types·화면 검증은 실행하지 않았다. [Root 준비 계약](Physics-Hinge-Two-Body-Pair-World-Selected-Preparation), [API](Physics-Hinge-World-Selected-ABI), [controls](Physics-Hinge-World-Selected-Controls)와 함께 사용한다. 기존 완료 보고14개와 부모93개를 다시 실행하지 않는다. 실제 native 채택 기준과 reference authority/expectedRefusal/initial 문법은 [선택 문법 부록](Physics-Hinge-World-Selected-Reference-Grammar)에 정리했다. ## 1. 선택 요청과 응답

World 요청의 정확한 top-level 키는 `{op,config,sourceState,dt,commands,commandsRawHex,outcome,attempt,output,error,rawFrames,negativeZeroPaths}`다. op=`world-step`, outcome=`returned` 또는 `refused`. config는 원래 고정4몸체/2관절 rest 입력이다. sourceState는 앞 단계에서 독립 검증한 accepted public state다. dt=1/120, commands는 이 호출의 입력이다. output은 정확한 `{state,diagnostics}`이며 state는 실제 public return, diagnostics는 accepted diagnostic이다. 거절 때 output=null이다. attempt는 실제 copied last-complete-stage 값이다. error는 원래 알려진 PhysicsError의 safe record 또는 null이다. 예상 결과나 candidate row/basis/optimum seed를 넣지 않는다.

`rawFrames`는 정확한 six keys `{source,angular,motor,free,postContact,projected}`다. 도달한 full frame은 고정 body order의416B Float64LE raw hex이며 미도달 frame은 null이다. 몸체 순서는 pairA0,pairB0,pairA1,pairB1, scalar 순서는 p3/v3/q4/omega3이다. Pair projection208B raw는 선택 pairProgress.projectedRawHex에 보존한다. 전체 projected frame은 두 pair가 완료해야 존재한다. commandsRawHex는 원래 angular command 순서의24B씩이다. JSON 값과 raw 대응을 검사하며 zero 부호는 raw가 기준이다.

`negativeZeroPaths`는 정확한 `{sourceState,commands,attempt,output}`의 네 dense string arrays다. 각 값은 해당 own-data root에 상대적인 JSON Pointer다. Null root는[]다. 중복·미존재·숫자0이 아닌 경로는 REFERENCE_INPUT이다. Raw scalar와 겹치면 부호가 같아야 한다. Initial 요청은 정확한 `{op,config,sourceState,sourceRawHex,negativeZeroPaths}`이며 op=`initial`이다. 동일 four roots를 유지하되 sourceState 외에는[]다. Initial은 graph별 한 번, step 요청과 별도이며 motor/free/projection 호출이 없다.

새 outer reply는 `{ok,resolved,executionFailure,referenceStatus,metrics,reference,violations,error}`다. Status는 RETURN/PRODUCER_REFUSAL/MISMATCH/UNRESOLVED다. Protocol 오류 리터럴은 `REFERENCE_JSON / hinge world reference line must be valid JSON`, `REFERENCE_INPUT / hinge world reference input is invalid`다. 두 경우 outer=false/false/true, UNRESOLVED, metrics/reference=null, violations=[], safe error={code,message}다. 실제 숫자의 gate 실패는 resolved MISMATCH이며 malformed 입력으로 바꾸지 않는다. Nominal strict cap 거절은 정확히 예측해도 실제 World NO-GO다.

## 3. Independent six-stage derivation

1. SOURCE: restore binary source13fields/body and remembered accepted report. Validate literal rest config separately. Source cursor n/time=n*dt is provider envelope authority; attempted n+1/time=(n+1)*dt remains World transaction metadata.
2. ANGULAR: independently execute original angular impulse+torque*dt/inverse-inertia leaf-rounded operations in original global body order, including zero additions. Keep input−0; output−0 follows each actual operation.
3. MOTOR: independently execute original per-joint motor on remembered angle, original signed endpoint rule, scalar inertia and clamp. No raw geometry substitution. Separate j/sBefore/sAfter and signed midpoint/spin work.
4. FREE: independently original omega/movement bounds, scalar quaternion advance then original linear operations and p advance. Scalar sin/cos/hypot seeds are binary calculations, not Decimal transcendental certificates.
5. POSTCONTACT: independently inspect all four cross-group sphere pairs in original pair order at all8 passes. The named successful profile admits no detector hit, including exact touch. This proves expected POSTCONTACT=expectedFREE raw; candidate detector null alone is not proof. Connected pairs remain excluded. If genuine contact/touch occurs, retain original native contact work and classify named physical NO-GO; do not seed expected POSTCONTACT from actual or expand into an independent contact solver campaign.
6. PROJECTED: independently compute each POSTCONTACT pose, centered momentum targets/rows/H/x0, Fraction branch optimum and Decimal80/120 raw+normalized measurements using unchanged parent functions. Targets/report baseline are POSTCONTACT, never FREE or prior zero momentum. Independently derive J/K, target report memory, cap and signed work. Actual rounded output receives a separate certificate and geometry/budget comparison. No candidate rows/axis/basis/u/parent-output seed determines expected optimum.

Previous accepted candidate state is admissible per-step ORIGINAL input only after the prior independent accepted-step gates pass. It is not an independently expected global trajectory cache. Each ask recomputes expected work cold, no expected answer cache, no parent14/93 replay. Preserve independent per-step and long-run COM/P/L/work gates already proposed; raw/norm1e-12, algebra1e-25, scalar1e-12, parent original SI gates and strict .01 cap remain unchanged.

## 4. Failure priority and safe persistence

Original order: disposed→dt→MAX_STEPS→command parse→EACH joint axis admission→angular/motor/free bounds→contact passes→pair0 projection/report→pair1 projection/report→finite diagnostics/original result validation→copied observer→strict hinge0/hinge1 caps→single commit. Original result validation is within the selected calculation catch, before observer/caps/commit. Registered observer at most1 and outside calculation catch. Observer throw wins over later cap and propagates exact received identity. Admission callback0. Known earlier errors preserve exact class/code/message and completed stage; no conversion to CAP.

Unknown received values propagate unchanged without new reflection/serialization; the inherited typed-parent proxy boundary remains a limit on this guarantee. Harness records only safe phase, known-vs-unknown flag, counts and previously copied safe data; identity is asserted in memory by a separately counted control. No fabricated known error/reference request. If safe producer outcome cannot be obtained, preserve EXECUTION_FAILURE and stop. Reference child exception/no reply/protocol/unresolved/storage/IPC failures are EXECUTION_FAILURE. Resolved actual geometric/work/momentum/report disagreement, nominal original numeric refusal and any cross-group contact are physical World NO-GO. Stop source at first failure, then later graphs execute the same frozen prefix once; no tuning.

Persist request exact JSONL bytes synchronously BEFORE sending. Capture stdout/stderr raw chunks before parsing; drain pipes to child close before final receipt. Keep first rejection, add secondary close/storage failures separately. Exit receipt has code AND signal, exact stdin/stdout/stderr byte counts/hashes, complete-line counts, trailing fragment bytes and paths. Stderr counts use raw bytes, not reconstructed UTF8 length. A nonzero exit/missing reply is not an expected numeric refusal. Preserve malformed stdout, partial LF/JSON and first failed request; never synthesize its reply. Accepted diagnostics/cache/cursor remain prior values on all refusals; attempt and accepted traces remain distinct.

## 5. Exact metrics field grammar

Fixed phase order is `source,angular,motor,free,postContact,projected`. Fixed pair array length2 is hinge0,hinge1. JSON objects have only listed own keys; arrays are dense. E means finite NONNEGATIVE maximum absolute error, or null iff its corresponding actual comparison was not reached. B means boolean or null iff unreached. Never use Number(null), bool-as-number, missing/sparse fields or finite coercion. A reached exact zero comparison is numeric0; unreached is null. Complete RETURN requires all actual-frame/error/report/work fields reached and both parentActualQualified=true. Producer refusal permits only its honest reachability null mask. Outer unresolved is EXECUTION_FAILURE before any physical numeric gate.

`metrics` exact keys remain `{actualCompared,pairActualCompared,checks,frameErrors,pairErrors,contactChecks,reportErrors,workErrors,precision}`. actualCompared is boolean; pairActualCompared is two booleans, false for no complete actual projection. No parent prediction defaults qualify actual comparison. Unknown producer cannot supply a fabricated metrics record.

**checks exact keys**:

**frameErrors** is exact six-phase object, each value null or `{positionM,quaternion,velocityMps,angularVelocityRadps,metadataMatch}`. ## 7. 저장·종료·수량 선택

Main1,024MiB + fixed64MiB + emergency8MiB =1,096MiB다. 요청256KiB, 전체 reply512KiB, compact receipt4KiB다. SOURCE1,200단계의 IPC 계획 상한900MiB, receipt4.6875MiB, global raw2,995,200B와 initial416B 및 실패 여유를 main에 포함한다. Controls<=32MiB는 fixed에 포함한다. 이 값은 실제 World 크기의 측정이나 모든 입력에 대한 보장이 아니다. 중간292/584MiB 계획은 선택 전에 대체했다. 물리 입력·cap·수치 gate는 바꾸지 않았다.

전체 실제 stdin/stdout/raw를 저장한다. Canonical receipt는 byte ranges/hash/호출/판정만 연결한다. Summary는 counts/extrema/first-failure locator만 유지한다. 전체 observations 배열을 중복하지 않는다. Repeat/compiled는 실제 호출과 전체 byte 비교를 한 뒤에만 SOURCE bytes의 검증 alias를 저장한다. 차이가 있으면 actual divergence prefix를 emergency에 보존하고 중단한다. 세 graph 전체 IPC를 중복 저장하는2,700MiB 계획은 선택한 한도 밖이다. 압축률이나 alias를 SOURCE budget에 가정하지 않는다. Runtime 저장 한도는 Git archive 추가 복사나 부모 Fraction 내부 메모리 상한이 아니다. Archive bytes는 별도 기록한다.

Overflow 뒤 새 요청·World 호출은0회다. Stdin 종료와 SIGTERM 후 실제 close를 최대5,000ms 수집한다. 종료되지 않으면 SIGKILL 한 번과 추가5,000ms drain을 적용한다. 종료되지 않은 pipe의 completeEOF=false, 실제 captured prefix/hash/trailing fragment/signal을 보존한다. Complete drain이 없으면 GRAPH_NO_COMPLETE_PROOF다. 저장/transport 오류를 수치 World NO-GO로 표시하지 않는다. 각 transport buffer8MiB와 emergency disk8MiB는 별도다. 전체 payload 예정 hash와 실제 저장 prefix hash를 혼동하지 않는다. 한도를 올려 성공 prefix를 다시 실행하지 않는다.

Full main GO의 graph별 계획 수: actual World step1,200, initial+accepted state1,201, motor/projection/report 각각2,400, 몸체 angular/free 각각4,800, contact passes9,600, producer detector38,400, 독립 final checks4,800, global full raw frame7,201, pair phase blocks14,400이다. Graph3개면 main3,600회·pair projection7,200회·global raw21,603개다. Controls·실패·protocol 요청·부모 precision/expected/actual solve는 별도 actual 수를 기록한다. 이 수는 완료된 실행 결과가 아니다. 실패하면 attempted n+1와 accepted n을 구분하고 도달한 실제 prefix만 기록한다.

각 stream에 bytes/SHA/LF/ordinal/offset/trailing/completeEOF를 기록한다. Source/dist closure·bundle·emitted·build/types·owner 출처는 canonical parity 밖의 고정 provenance다. 실패한 요청이나 원래 stderr를 재구성하지 않는다. Parent schema/solver/허용값을 바꾸지 않는다.
