# Coupled dynamic contact: private World profile

원래 before·at·after 세 입력을 실제 World와 recorder 경로에서 검증했습니다. 소스와 NodeNext 컴파일 경로 모두 세 스텝을 승인했습니다. before·at은 정적 접촉이며 after는 동적 마찰입니다. 공개 패키지의 정식 API 채택은 별도 단계입니다.

[CLEAN-RESULTS.md](CLEAN-RESULTS.md)는 실제 실행 결과입니다. [CLEAN-PROTOCOL.md](CLEAN-PROTOCOL.md)는 실행 전 고정한 기준입니다. 이전 정적 전용 후보의 동적 거부와 원래 실패 기록은 그대로 남아 있습니다.

지원 범위는 질량 1 kg인 단위 정육면체와 고정 상자, 이전 접촉 캐시가 없는 단일 접촉점, 첫 시간 구간입니다. 원래 세 입력·시간 간격·재료·좌표를 그대로 사용했습니다. 중력·초기 회전·반발·명령·위치 보정은 0입니다. 전체 충격량 J를 한 번 적용하고 원래 8×8 슬롯의 나머지 63회는 실제 0 충격량 호출로 실행합니다. 스칼라 솔버로 돌아가는 경로는 없습니다.

연속 구간, 이전 구간 캐시 사용, 여러 접촉점, 일반 관성·재료, 장시간 적층과 동적 브라우저는 이 검증에 포함되지 않습니다. 적용 후 실패·기록·복원은 별도 캠페인입니다. HOLD와 공차는 유지하며 배포하지 않습니다.
