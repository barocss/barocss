## Proposed library delta

Only `src/stack/frictionless-island.ts::worldInverse` changes after Root authorization. The static zero and exactly equal local-diagonal branches remain. For anisotropy, obtain the three represented rotation basis vectors from existing `rotate(q,e_k)`. Construct the six independent entries of the bilinear form `R diag(d) R^T`, evaluating each off-diagonal entry once and assigning that value to both positions. This is direct construction of a symmetric tensor. It does not average, repair, threshold, or symmetrize the old separately rounded columns. There is no quaternion snap or normalization in this patch.

In exact real arithmetic, the existing rotation map is linear and its conjugate map is its transpose, so this bilinear form is the same mathematical operator as the old quaternion application for a unit quaternion. A represented quaternion has a small norm error. The independent reference therefore uses normalized quaternion sandwich arithmetic and measures that discrepancy; compatibility with the unchanged Float application is an actual gate, not an assumed identity. A nonphysical or poorly conditioned input can still refuse.

## Independent private reference

It rotates by `q*(v,0)*conj(q)/dot(q,q)`, independently builds the physical inverse tensor by acting on basis vectors, and evaluates physical inertia by the reciprocal principal values. This algebra is separate from the proposed shared Float bilinear expression.

For each solved noncontact packet it checks: exact represented symmetry and positive leading principal minors; tensor entries against the normalized physical tensor; trace, second spectral invariant and determinant; nonzero angular-load action, incremental spin, angular momentum round trip and rotational energy. Spectrum diagnostics use dimensionless relative-to-`max(1,|reference|)` residuals at `1e-10`; physical tensor/action/momentum/energy residuals use absolute `1e-10`. These extra spectrum checks do not replace any existing physical gate. Static tensors are exactly zero. Isotropy must remain exactly diagonal. All body words remain unchanged for a no-contact private preparation. This phase does not integrate, apply an actual contact impulse, or prove a trajectory.
