# D369 보고 — 연관 2D 밴드 (B1)

오너가 2026-10-30에 요청한 "한쪽 도형이 커지면 같이 변하는 밴드"의 2D 판입니다. 소스 커밋은 `4a135b1cb`입니다.

## 기능

- **만들기**: 스케치에서 Band 도구(M)로 닫힌 도형을 두 개 이상 고르고 Make band를 누릅니다. 고른 도형은 construction(참조 도형)이 됩니다.
- **저장 방식**: 스케치에는 "어떤 도형을 감는지(side id)"와 offset·width만 저장합니다. 결과 형상은 저장하지 않습니다.
- **재생성**: 평가할 때마다 바깥 외곽을 정확히 다시 만듭니다. 결과는 공통 접선과 원호로 이루어집니다.
  - 원본 도형을 고칠 때, 매개변수를 바꿀 때, Undo, 파일 열기 모두 항상 새로 계산합니다.
  - width를 주면 띠 모양(strip)이 됩니다.
- **거절**: 다음 경우는 밴드 이름을 넣은 메시지로 거절합니다.
  - 도형이 겹치거나, 닿거나, 한 도형이 다른 도형 안에 있음
  - 외곽에 닿지 않는 도형이 있음
  - 오목한 도형
  - 커널 한계를 넘음
- **편집**: Extrude 편집기에서 밴드 offset·width와 원본 원의 반지름·중심을 고칠 수 있고, 매개변수로 묶을 수도 있습니다.
