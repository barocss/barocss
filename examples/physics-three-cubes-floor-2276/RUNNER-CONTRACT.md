# Three cubes on floor: finite public runner

This is a new four-body public `rigid-persistent-box-v1` case. It uses the existing qualified direct frictionless island route. It does not change the engine, tolerances, or body cap.

Root alone runs `node examples/physics-three-cubes-floor-2276/run.mjs fresh-id --build-manifest examples/physics-coupled-cubes-floor-2276/evidence/public-build-01/result.json` under an outer 180-second guard. One internal 170-second deadline covers both graphs, references, disposal and final authentication. No build occurs here.

Each graph creates one World and one recorder from `makeCase()` only. Initial state and every returned state are retained with all finite numeric binary64 words. Empty commands are passed to every step. Both graphs first reach 32, and each complete 33-state packet must pass the independent three-DOF oracle. Neither graph may advance beyond 32 until both replies and complete Source/Native state/word parity pass. The same World and recorder then continue to 256. Each complete 257-state packet must pass the independent oracle. This is exactly two reference calls and 256 accepted steps per graph on success. There is no restore, hidden factory, pose injection, or expected future engine input.

The oracle checks complete prefixes at the two declared checkpoints. A failure in an earlier transition is detected at its checkpoint, not claimed to have been checked at its arrival. `passedIndependentTransitions` advances only after the complete checkpoint reply passes. Attempts, returned accepted steps and independently passed transitions are separate counters. First detected failure stops all future engine work. The actual prefix is saved before each reference call. Step refusal saves state/model/recorder before and after with all words, error classification and exact retention result. Terminal owner data and partial counts are retained when available. An error cannot become a physical PASS.

Prerequisites are the actual coupled trajectory256+restore/regression, public failure controls and desktop word/pixel PASS receipts. Loaded Source and canonical Native code must match the paid public-build manifest and actual reachable package source hashes. Only runtime AST import/export edges are followed; documentation updates are not execution inputs. Actual harness, model helper, case, oracle, contracts, Node/Python/TypeScript tools and prerequisites are frozen before import and rechecked after cleanup. Old two-body state traces are not a physical oracle for this new chain.

Caps remain 48 Worlds/1024 accepted steps, 16 MiB evidence per graph (shared metadata is charged to both), 2 MiB request/reply/artifact, 512 KiB numeric words, finite/depth/node transport limits and the original recorder 512-frame/1-MiB policy. Actual success uses one World/256 steps per graph; no cap is raised if recorder admission refuses. Provider digest string is the sole Source/Native normalization. Numeric words, every state field and initial model are otherwise exact. Desktop remains NOT_RUN until a separate actual same-stage test. No general dynamic-eight or broader-profile claim follows.
