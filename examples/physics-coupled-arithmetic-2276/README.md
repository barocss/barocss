# Shared arithmetic qualification

소스와 실제 NodeNext 컴파일 경로에서 생산 회귀 13회와 별도 산술 경계 52회를 각각 통과했습니다. World 호출은 0회입니다. 이 결과는 동적 마찰의 실제 World 적용을 위한 선행 검증입니다.

- 생산 경로: 기존 세 물리 입력, 여덟 거부 입력, 두 직접 정적 계산. 이전 efficient 후보의 전체 결과·증명·연산 계수가 원본 바이트와 같습니다. 상한은 16회입니다.
- 별도 시험 경로: 알려진 인수의 다항식, 근 선택·중복·끝점, IEEE 이진64 반올림·부호 있는 0·오버플로, 낮춘 자원 한도와 한도 상향 거부. 독립 관찰자가 각 결과를 즉시 검사했습니다. 52회이며 상한은 64회입니다.
- 두 경로는 실제 같은 산술 코어를 사용합니다. 생산 진입점에서 시험 진입점과 한도 변경 경로에 도달할 수 없습니다.

합계 65회는 서로 다른 프로세스의 13회와 52회입니다. 하나의 64회 상한 안에서 실행했다고 주장하지 않습니다. 모든 기존 수치 공차, 연산 가격, 8×8 물리 반복 상한은 그대로입니다.

[실행 결과](RESULTS.md), [최초 계약](PURE-PROTOCOL.md), [타입 수정 02](SETUP-AMENDMENT-02.md), [선언 수정 03](SETUP-AMENDMENT-03.md)을 구분해서 읽으십시오. 첫 TS18048 실패와 두 번째 TS4060/TS4058 실패는 원본 소스·stage·출력과 함께 보존했습니다. 수정은 자바스크립트에서 사라지는 타입 표기 두 곳뿐입니다.

실행 명령은 계약과 수정 문서에 있습니다. 같은 출력 ID를 다시 쓰지 마십시오. 새 실행은 새 ID와 별도 증거가 필요합니다. 실제 World, 장시간 적층, 동적 브라우저, 공개 API 채택과 성능은 이 검증 범위에 없습니다. HOLD·NO_GO·최초 실패는 유지합니다. 배포와 릴리즈는 하지 않았습니다.
