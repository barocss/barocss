`python3.13 -B materialize.py FRESH_DIRECTORY`

separate protocol, with170s internal/180s external, before generated-bank seal.
It makes no candidate, GCD materializer, position proof, World or baseline call.

M1 uses Python exact integer literals and str for the decimal oracle. Binary64
oracle uses stdlib struct.unpack('>d',bytes.fromhex(word)), isfinite and
float.as_integer_ratio. The ratio is explicit reduced n/d, including0/1 and1/1.

NaN/Inf are rejected before ratio conversion; raw input words are retained.
