# D355 보고 — 스케치를 다시 열어도 직사각형 측면 ID 유지

로드맵 09의 여덟 번째 한정 항목이다. D354 감사에서 발견한 기존 결함이며, 소스 커밋은 `9c97ec8b9`다.

## 문제

스케치를 다시 열고 아무것도 바꾸지 않은 채 Finish만 해도, 직사각형의 측면 ID가 새로 매겨졌다.

- 구멍이 있는 직사각형은 e1–e4가 e6–e9로 바뀌었다.
- 위쪽 오른쪽 모서리부터 그린 직사각형은 fillet이 **부피 변화 없이 다른 모서리로 조용히 옮겨졌다.**
- construction 직사각형은 실제 형상으로 바뀌었다.

## 수정

직사각형을 외곽선으로 바꿀 때 측면 ID(변별 대응)와 construction 표시를 그대로 옮긴다.

## 검증

- **Model**: 새 테스트 9개, 115/115 PASS. 수정 전에는 6개가 실패한다.
- **Studio**: 49/49 PASS.
- **독립 Opus 감사**: PASS. 48가지 경우에서 모두 측면 ID가 유지됐고(수정 전에는 43가지에서 이름이 바뀜), 변이 8개를 모두 잡았다.
- **실제 Studio run01**: PASS. 세 가지 흐름을 실행했다.
  - fixture를 그대로 다시 열기 → Finish
  - 폭을 70으로 바꾼 뒤 Undo/Redo → 저장 → 새로 열기
  - Bézier를 먼저 그린 직사각형
  - 세 경우 모두 측면 ID가 유지됐고, 오류는 0이었다.

수정 전 코드로 Studio 기준선을 돌리려고 임시로 되돌리는 것은 권한 분류기가 거절했다. 그래서 재현 근거는 모델 probe와 실제 hook의 음성 대조다.

전체 검사, 원격 CI, 릴리스는 NOT_RUN이다.
