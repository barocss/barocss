This folder alone is new. Protected examples, P03, production source, Studio and held SDK paths are unchanged. The author uses the Playwright skill's CLI workflow and existing installed tooling, without running a build, browser, helper, observer or World. Root owns execution after matching review and frozen inputs.

The UI bundle contains Viewer/GPU/CAD display code from this checkout via physics-lab's own-package resolver. Physics is explicitly external at /physics/entry.js. The local server authenticates all qualified warm-native build-01 staged and emitted bytes before bundling and serves the actual entry-reachable emitted ESM files without rewriting or substituting a Source bundle. Every emitted browser request remains on owned localhost. The UI bundle rejects an accidental canonical packages/barocss-physics source import. Scene build records actual own-checkout input hashes, output hash and actual immutable emitted provider inventory. It does not regenerate any physics provider or run a World.

Actual GPU triangle packets use the exact fixed collider box half extents, in mm, through the unchanged existing box-slab/PhysicsLab Viewer path. There are three packets: cube, floor and a green accepted-point annotation. Distinct original display surface IDs bind each body to accepted COM m→mm once and accepted XYZW/scale1. This is display-only geometry, with NO original CAD nativeSurface authority claim. Static source review found that current Viewer permits at most4 surfaces and one-to-one motion targets; two full native six-face boxes would exceed that existing API, so no such unsupported path or SDK edit is used. Full/detail Viewers share the SAME actual accepted snapshots and differ only in camera. Contact annotation crosses stay centered exactly at accepted Contact.points.anchorM. Pair J [Ns] and Mworld [Nms] are shown separately; no interval aggregate is falsely placed at the accepted point.

Full scene and closeup are separate actual GPU Viewers sharing the SAME copied accepted snapshots. The closeup changes camera only; physical geometry and time are not scaled. Renderer replay cycles saved accepted snapshots without stepping World. Current live accepted clock and displayed recorded clock are separate UI fields. View selections, RAF, camera, panel, marker toggle and resizing never call World.step. The finite six action buttons use synchronous stage/busy/disabled guards. There is no reset, profile switch, continuous solver loop or cap increase. One boot lease per server lifetime rejects reload; root starts a fresh owned server and Chrome session for a new proof.

Hidden actual constructor/step traces match independently checked A0/A1 with only bijective diagnostic World/attempt/query/pair alpha-renaming; every physical word remains. The read-only snapshot API exposes copied actual checkpoints, live state/recorder/cache, phase counts, Viewer native packets/motion/cameras/projections and raw words. The10 frozen CLI checks cover actual GPU pixels in both views, mm/XYZW/worldmatrix/native projection/contact markers, finite step/record/public wire/restore UI, desktop1280/1440/1920, camera/panel visibility, replay clock/count invariance, live D2 raw A2 equality, bounded raw export and zero page/console/network errors.
