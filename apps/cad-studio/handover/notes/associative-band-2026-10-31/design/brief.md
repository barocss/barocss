## 2. Data model
doc.ts: `export interface SketchBand { version: 1; id: string /* 'b1' */; sources: string[] /* ≥2 side ids */; offset?: Dim /* ≥0, default 0 */; width?: Dim /* >0 strip */ }` and union arm `({ kind:'sketch'; profile:'band'; band: SketchBand } & OnPlane)` at doc.ts:303 (no copied geometry; exhaustiveness forces every reader to resolve or refuse).
Reference = one side id (shape ids[0] when made), resolving to the unique construction shape whose ids contain it. Missing → "Sketch N band b1: source e5 is not in the sketch (deleted, or no longer construction); pick the sources again". Two refs to one shape → refused (ambiguous). Never positional rematch. Trim/split turning a circle into an open arc → "source e3 is not a closed shape".
Identity: Finish calls withIds on all shapes before profileOf and the refs split (idempotent) so construction is stored with ids; sketchShapes seeds k from construction ids too; for profile:'band' returns {shape:null, done: construction resolved}; SketchState.band carries it like association (types.ts:52-70); rebindDims.slotsOf gets a 'band' slot (offset/width named) + one slot per construction shape keyed c:<ids[0]> with named per-value restore for circles, so bindings on sources/offset/width survive reopen→Finish. Undo/Save = plain JSON; migrate does not validate sketch profiles.

## 3. Geometry — new packages/barocss-cad-model/src/sketch/band.ts (module-level functions only)
Inputs: each source via shapeNode → loopOf, made CCW (reverse if area < 0). Convexity: all arcs ccw (outward) and at each joint cross(prev dir, next dir) ≥ −1e-9·scale², else "source eK is not convex (v1 bands wrap convex shapes only)".
Generators (source, sideId, c, ρ = r + d, cone [a0,a1]): each arc segment → its circle, cone angle(start−c)..angle(end−c); each vertex → r=0, cone from previous piece end outward normal to next piece start normal (line a→b normal atan2(−dx, dy)); empty cones (tangent joints, width ≤ 1e-12) skipped; full circle cone [0,2π); lines no generator. Per source cones tile the circle exactly → h_i(θ) = c_g·u(θ) + ρ_g. Offset exact (h(K⊕B_d) = h(K)+d). Caps: ≤ 32 sources, ≤ 256 generators.
Pairwise first (d = 0): dist(A,B) = max_u [−h_A(u) − h_B(−u)] over the common refinement of A's cones and B's cones mirrored by π; on each interval the term is (c_k − c_g)·u − ρ_g − ρ_k, max at u = dir(c_k − c_g) if inside else an endpoint (closed form). dist < 1e-4 → "sources eA and eB overlap" / "touch or are closer than 0.0001 mm". Containment "source eB lies inside eA" when h_B ≤ h_A everywhere (same breakpoints).
Envelope: candidate angles = all cone endpoints + crossings of generator pairs from different sources: Δ = c_g − c_k, φ = atan2(Δ), D = |Δ|, θ = φ ± acos((ρ_k − ρ_g)/D) when |ρ_k − ρ_g| ≤ D. Sort, merge within 1e-12 rad, argmax over sources at interval midpoints; a tie within 1e-9·scale between different sources → refused (shared outline). Merge consecutive same-generator intervals.
Loop: winner with ρ>0 → arc {kind:'arc', start: c + ρu(θj), center: c, direction:'ccw'}; transition g→k at θ → line from c_g+ρ_g·u(θ) to c_k+ρ_k·u(θ) (common outer tangent, ⟂ both radii). Same-source transitions of length ≤ 1e-7 merged; tangent between sources < 1e-4 → refused (coincident tangent points); an arc with ρ·Δθ < 1e-4 collapses to its midpoint. Source polygon edges come out as vertex→vertex lines.
Refusals (all name "Sketch N band b1"): < 2 sources; missing/duplicate/non-construction/open source; non-convex; overlap/touch/containment; a source that wins no interval ("source eK does not reach the band's outline (no tangent): remove it from the band" — never dropped silently); one source wins all (containment); offset < 0 or non-finite; 0 < width < 0.01; any arc 0 < ρ < 0.01; coords beyond ±10000; tags > 32 chars.
Width: strip = loop at d as a hole inside the loop at d + w.
Tags (stable while hull topology is unchanged): arc `${id}${L}_${sideId}`; tangent `${id}${L}_${fromId}_${toId}`; `_${n}` suffix when the same piece repeats; L = '' single loop, 'o'/'i' outer/inner of a strip.
