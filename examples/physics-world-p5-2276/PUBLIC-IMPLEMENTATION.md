# Bounded public P5b qualification

`public-run.mjs` executes one parent-frozen graph. It never starts the next graph.
`public-trial.mjs` authenticates all inputs before importing providers. The parent
must freeze the exact command, helper, source, model asset, criteria and native
provider files. Native execution also requires a reviewed source PASS summary.

The runner executes the exact 101 factory attempts and 6334 step entries. It
checks actual inner World entries, accepted commits, initializers and solver
calls. The fixed binary ledger is updated at actual factory/step/commit sites.
These writes are included in measured public step cost. Helper counts stay in
memory and are saved at bounded progress points and on the first failure.

The source observer uses owned source paths. The native observer stages the
actual emitted root bundle, native sibling modules, CAD dist and publish maps.
It does not rebuild or rebundle the native numerical root. Actual root/error
identity and recorder attachment test the shared class and registry. A class or
registry mismatch fails before the numerical cohorts. Counter/fault insertions
exist only in isolated test outputs. Production sources remain unchanged.

`PUBLIC-RECIPES.json` freezes measurement methods, limits and exact calls.
`P5B-CONTROL-RECIPES.json` freezes all literal invalid models and commands.
`public-source-check.mjs` only reads/parses source text and overlay text. It does
not evaluate a provider, construct a model, invoke a helper or build a package.
Static checks cannot establish a runtime PASS.

The runner uses the original cloth oracle once captured in `evidence/oracle-01`.
It checks all 241 authenticated frames at the original 1e-12 gate. It does not
regenerate research data. Old public cloth hashes/residuals and exact fluid
release hash tables remain separate gates. New numeric fingerprints retain
negative zero. Unknown zero signs erased by old JSON remain unknown.

The real cloth host controller supplies the four-World/five-step headless seam.
A Viewer-submit fixture throw is external to World. This is not browser proof.
The rigid recorder cohort invokes no restore, serialization or deserialization.
The numerical cohort does not auto-run standalone probes or documentation
samples. Docs runtime, product UI, GPU completion, release and other roadmap
qualification remain separate.

The owned child guard has a 180 second deadline, bounded TERM/KILL, pipe EOF,
close and process-group absence gates. Artifacts use fresh names. The first
unexpected failure is retained. No automatic retry or count/tolerance expansion
follows. Sixteen MiB of authored output, 32 MiB of native staging, four MiB of
logs, four MiB of reused oracle data and eight MiB of emergency reserve fit the
64 MiB cap. Read `resource-summary.json` and `exit.json` as separate numerical
and process-lifetime evidence.
