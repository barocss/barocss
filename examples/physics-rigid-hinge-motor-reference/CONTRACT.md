## 4. report와 work의 고정 정의

baseline은 **projection input FREE**다. 각 body i에 대해 원래 sub 먼저, scalar scale 다음 순서로

- `J_i = (1/inverseMass_i) * (v_projected_i - v_FREE_i)` — N*s.
- `K_i = parsedScalarI_i * (ω_projected_i - ω_FREE_i)` — N*m*s.
- jointReport는 기존 `{id,kind,aId,bId,angleRad,linearImpulseNs,angularImpulseNms,motorImpulseNms}`만 쓴다. linearImpulseNs=J_B, angularImpulseNms=K_B, motorImpulseNms=실제 j. motor를 correction에 다시 더하지 않는다.
- angular report norm **>.01만 거절**, equality는 통과한다. `.01`에 tolerance를 더하지 않는다. 선형 report는 기존처럼 finite만 요구하며 새 cap을 만들지 않는다.
- scalar I는 원래 `.4*mass*radius**2`의 parsed binary 값이다. K 계산은 새 명시된 scalar report이며 원래 inertia(body,delta)의 bit parity를 주장하지 않는다. KKT 승수·force/dt·calibrated reaction으로 바꾸지 않는다.

motor before는 angularBodies, after는 motorBodies다. `sBefore=dot(ωBbefore-ωAbefore,axis)`, `sAfter=dot(ωBafter-ωAafter,axis)`. **motorWorkJ = (j*(sBefore+sAfter))*.5** 순서로 계산한다.

spin-only 비교는 A 다음 B 순서다: 각 i에 대해 sub로 Δω, add로 ωbefore+ωafter, xyz dot, `(.5*I_i)*dot(Δω,sumω)`를 만들고 두 body 값을 더한다. 큰 total KE 두 값의 차이로 work를 정의하지 않는다. source→angular external work, motor work, free-integration energy, projection ΔK, parent objective를 각각 기록한다. energy는 finite/nonnegative 검사만 하며 자동 conservation/dissipation을 약속하지 않는다.
