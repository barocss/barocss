# Staged geometry depth mapping

The private stage preserves the qualified B constructor code, except for relocating its private import to the copied native constructor. No old floating box detect or scalar solve supplies a persistent B box result. B MISS stays MISS. B UNRESOLVED becomes a typed NUMERIC_LIMIT before commit.

The explicit geometry mapping uses each B paired endpoint and B represented normal:

`penetration = max(0, max_points(-dot(bPointM-aPointM, normal)))`.

This is SAMPLED_PATCH_DEPTH: a B paired-witness patch depth, not full-box SAT overlap or a global minimum translation depth. It is a geometry delta. It does not retain the old floating SAT overlap metadata. Both represented endpoints, exact endpoint fractions, normal and mapped depth are saved in every query. The independent observer verifies native surfaces and the line/box exits with exact Hamilton geometry and slabs, and compares mapped depth with exact endpoint projected depth at 1e-12 m. Endpoint float presentation and represented normal-line residuals are separate gates. A separate independent gate constructs exact Hamilton native support intervals along the FIXED reported normal, then computes full directional overlap with Decimal 80/120 normal-length diagnostics. Sampled positive depth must agree with that directional overlap within 1e-12 m. A mismatch is GEOMETRY_DEPTH_NO_GO. This observer answer never replaces producer depth and is not a source fallback. No global minimum over 15 axes is asserted. This mapping does not qualify complementarity, projection energy, convergence or stability.

The second explicit delta dispatches both FACE and EDGE B point lists into the actual persistent solver. It retains native feature point IDs, eight outer passes, eight alternating inner iterations, original normal targets, cache copying/warm law and scalar/vector updates. The first audit does not repair frame transport or the public aggregate. Exact query records remain separate from force events and the final accepted-pose query.

The actual apply primitive emits its actual J, common anchor, body COM/pose/velocity/spin before and after, cache state, frame/feature and native provenance. Actual zero-vector applications remain applications. A normal zero branch that never calls apply is separately labelled normal-zero-no-call. Projection is separately traced. An accepted cursor and frame sidecar are allocated before, then assigned within the existing assignment-only commit boundary. Rejected diagnostic attempts do not advance them.

The observer uses a uniform unit cube's physical inertia 1/6 and exact represented words, not producer inverse inertia or candidate solver algebra. It checks event/step linear and spin momentum, midpoint work, net passive contact work, kick/drift/projection bookkeeping, native query geometry, public impulse vector and public world-origin moment. A public averaged point is not assumed to represent pressure moment.

Raw retry/restore physical traces exclude only diagnostic world ID, attempt ID, query ID and generated query pair.id. No numerical physical word, actual cache vector, native feature/point identity, frame normal or branch is normalized. World state and recorder comparisons remain raw exact. Query numbering is observational and changes after failed attempts.

The first physical/report/geometry gate failure stops the runner after its complete returned one-step trace has been saved. Later fault, retry, clean-control and restore checks remain NOT_RUN. The maximum plan is the frozen three-World/eight-attempt plan; no extra serialization replay occurs.

Correction events carry their actual query identity. The observer checks query/prepose ownership, normal/depth correspondence and the physical inverse-mass correction displacement before accepting projection-energy bookkeeping. Every actual tangent increment is independently checked against its current normal; a zero final cache cannot hide a non-tangential unloading increment. Warm applications are checked against the logged scalar/current normal plus world tangent. Warm friction frame coverage requires a real prior-step cache hit, nonzero old tangent, a changed normal, and independently matching native active-halfspace point/feature correspondence; otherwise it remains NOT_COVERED.

The accepted public report point and normal receive their own native Hamilton line/surface/midpoint/paired-gap checks. A final B query or a passing wrench identity does not validate that public point. REPORT_GEOMETRY_NO_GO blocks promotion independently of vector or moment reporting.
