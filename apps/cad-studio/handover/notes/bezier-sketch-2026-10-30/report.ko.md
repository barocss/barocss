# D354 보고 — 제어점으로 2차·3차 Bézier 곡선 작성

로드맵 09의 일곱 번째 한정 항목이며, 소스 커밋은 `8c396c876`이다. #2051의 §2(Bezier 제어점 작성)를 구현했다. §1(원·호 작성)과 §3(extend와 split의 구분)은 별도 범위이므로, 이슈를 닫을지는 섹션별로 판단해야 한다.

## 추가된 것

- **도구.** Bézier 도구(B)로 제어점을 클릭한다. 3점이면 2차, 4점이면 3차 곡선이 된다.
- **표시.** 점선 제어 다각형과 실선 곡선이 구분되어 보인다. 곡선은 가운데 제어점을 지나지 않는다.
- **편집.** 패널의 BÉZIER 섹션에서 제어점 좌표를 고칠 수 있다.
- **저장.** 곡선은 프로필에 포함되지 않는다. 스케치와 함께 저장되고, 다시 열면 복원된다.
- **곡선 변환.** "Make curves"를 누르면 정확한 2·3차 NURBS 곡선이 되고, Loft guide로 쓸 수 있다.
- **방어.** 손상된 저장값은 무시하고, 퇴화된 곡선은 거절한다.

## 감사와 수정

독립 Opus 감사 결과는 CHANGES_REQUIRED였다.

- **필수 수정:** 손상된 저장값 때문에 앱이 멈추는 문제, 그리고 너무 약한 테스트(변이 13개 중 10개 생존).
- **그 밖에 고친 것:** Select 도구가 프로필에 닿지 않던 문제, construction 모드 처리, 퇴화 곡선, 오류 메시지 누락, 문서 과장.

## 검증

- **Model:** 새 테스트 15개, 영향 범위 271/271 PASS.
- **Studio:** 새 테스트 5개, 48/48 PASS.
- **타입·lint·docs:** 모두 PASS.
- **실제 Studio run03:** PASS. 다음 흐름을 실행했다.
  - 2차 곡선 작성 → 제어점 편집 → Finish
  - 저장 → 새로 열기 → 다시 열기
  - 3차 곡선 작성 → Make curves → Undo/Redo → 저장 → 새로 열기
- **독립 Python 검증:** 2회 통과. B(1/2)=(10,45), 끝 접선 (20,±20)이 정확했고, 제품 계산과의 오차는 0이었다. 실행 오류도 0이었다.

## 남은 것

- 다시 열면 곡선은 보이지만 편집할 수 있는 현재 도형은 아니다.
- 연결된 스케치에서는 construction 도형이 저장되지 않는다(기존 문제).
- trim·extend의 경계로 쓰이지 않고, DXF로도 내보내지 않는다.
