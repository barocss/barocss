# D1252 — Draft two adjacent planar box sides

2026-11-14 · FULL · P5, rows 07 and 30 · [#2261](https://github.com/barocss/barocss/issues/2261)

The existing Draft command now takes exactly two adjacent, fully named sides on a verified cardinal rectangular solid. The neutral plane is the start of the signed cardinal pull. Positive and negative angles turn both planes at once. The kernel constructs their common straight edge and a closed six-face solid. Face and edge names and stored entity tolerances are retained. Upright inputs use a deterministic materialization namespace for internal IDs; the output is byte-equal across cold and cached evaluation and reversed selection order. The existing wedge and all-sides Extrude routes still handle their earlier profiles.
