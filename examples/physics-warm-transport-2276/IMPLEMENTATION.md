# Private warm transport implementation 01

Authorship is source-only. The author does not build, invoke the candidate, create a World, or run a physical observer. Root owns those executions after matching review and frozen pins. The original producer and real-warm-frame baseline remain immutable.

The baseline archive is `../physics-real-warm-frame-2276/EVIDENCE-01.tar.gz`. Its manifest authenticates 292 files and an uncompressed tar stream of 9,615,360 bytes, below 16 MiB. The original first real warm event failed the unchanged tangent-plane gate. Preserved setup review records explain the two-label run-source mismatch and matching review before the actual run. This experiment does not relabel that result.

`pin-sources.mjs` authenticates the original producer SOURCE-PINS-03 dependency closure, complete executed build-01 stage and bundle, exact real-warm model/options/reference, original failure receipt, new independent Gram bank and all new authored files. It creates a fresh source receipt and executes no helper or physics. `build.mjs` checks that receipt before importing the stage transform. It copies the complete qualified staged closure and checks every copied byte against the old build receipt. This closure already contains the qualified producer transform. High's warm-only transform then inserts the helper assignment before the existing warm apply return. Its contribution return and accumulation path remain unchanged. The trace's raw cacheBefore snapshot still precedes the helper mutation. No observer data is used by the producer.

The only staged changes are the new warm helper, its import and call in persistent-box-contact, the private test entry export and the generated provider manifest. All other staged files, including private-phase instrumentation, B geometry, canonical STATE2 and recorder2, retain their original hashes. A new complete source inventory excluding only the generated manifest defines provider identity; the final executed inventory separately includes that generated manifest and the entry. The bundle metafile must resolve entirely inside this new closure. Distinct provider and bundle hashes are required. The old provider is never modified.

`freeze.mjs` performs no imports from the candidate graph. It checks the build receipt and every final staged file, the independent input reference, and the independent nine-case Gram receipt, then creates the final frozen runtime input map. `run.mjs` validates that complete map before candidate or encoder imports. It calls the helper on all nine original bank inputs and saves original/after-input/output words and typed refusal diagnostics. `bank-observer.py` independently recomputes Fraction Gram, authenticates the exact bank rational values, checks component and plane errors at 1e-12, and checks the typed zero-normal refusal. No World is created unless this bank passes. A helper-bank PASS does not qualify a physical step.

The World case uses the exact unchanged real-warm model-01 words; no height, quaternion, material, initial velocity or cache adjustment occurs. The runner starts one fresh Source World with the actual recorder, independently validates constructor accepted geometry, and attempts at most three steps. Full accepted states, private cache/provenance, clock, actual apply records, accepted contacts, pair wrenches and recording words are saved before the physical observer runs. A physical observer failure has priority over a warm coverage counter. The runner stops at the first physical failure or first fully passing interval with genuine prior-step/nonzero-raw-T/changed-normal/native-correspondence warm coverage. Three accepted steps without coverage produce COVERAGE_NO_GO. Unreached controls remain NOT_RUN.

The physical observer is a copy of the immutable real-warm observer. Its only equation changes are the explicit OBSERVER-AMENDMENT-01 warm block: independent Gram from raw prior T and actual n, cacheAfter comparison at 1e-12, unchanged normal cache words, actual J against both Gram and observed cacheAfter at the original 1e-10 vector gate, and projected-cache plane at 1e-12. Raw prior dot current n is retained as an ungated diagnostic. All native line, complete accepted contact population, signed-gap functional/sign, pose correction, physical cube inertia, momentum, work, reciprocity, wrench, origin moment, provenance and membership gates remain unchanged. No whole-step passivity follows from projection alone.

The immutable encoder and decoder use lossless compact DAG packets with complete root/subtree hashes and expanded byte counts. Every event and pose is retained. Compact per-attempt packets retain the full constructor and last actual attempt; the first-failure prefix retains full actual history. The 16 MiB evidence cap counts actual uncompressed serialized output bytes, including observer files, not gzip size. Runtime limits remain 1 World / 3 total attempts, 8192 records, 4352 applications, 72 B queries, 288 points, 7776 anchor checks, 16 MiB, and 180 seconds. The unchanged module-global caps are not raised. Each observer process uses the remaining wall budget. Root must use its command guard for the whole-process deadline and cleanup.

Root commands, in order, from repository root (the independent gram-01 generation already has its own receipt and must not be repeated):

```sh

node examples/physics-warm-transport-2276/freeze.mjs build-01 freeze-01
node examples/physics-warm-transport-2276/run.mjs freeze-01 warm-01
```
