# D878 — Create a circle from two circumference points and a radius

P1, rows 07, 09 and 16. FEATURE. The Circle tool offers a two-point input when the current drawing slot is empty. It uses the existing sketch plane and grid or object snaps. After two points, an entered radius shows the available circles. Select one explicitly to add an ordinary Circle. The saved profile contains the selected center and radius. Later edits use the existing circle controls.

The private planner compares the squared chord and diameter of the stored binary64 inputs exactly. An exact diameter produces one midpoint. A shorter chord produces two centers when the difference from the diameter exceeds 1e-7 mm. A longer chord, unresolved near-diameter or degenerate chord, invalid radius, or candidate outside the existing local sketch envelope is refused. Both complete candidate circles must fit within ±10,000 mm. The minimum radius is 0.25 mm. Both source-point residuals must be within 1e-7 mm. Centers are ordered by coordinates and retain their full precision.
