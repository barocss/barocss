# Lossless detached prepared-step packet prerequisite

Status: SOURCE_AUTHORED_NOT_RUN. Root alone executes the fixed20 tests. No
production helper, solver, compiler or test was invoked by the author. Own only
this new folder. The wholepath proposal remains a proposal; this module does not
implement scheduling, three credits, Python routing, archives or a1200 runner.

Use built-in Node22.19.0 V8 serialization/deserialization after admission. This
is internal test transport, not public API or a stable cross-version wire format.
Only ordinary Object.prototype records and dense Array.prototype arrays may
contain finite binary64 numbers, strings, booleans and null. Root is a record.
Shared acyclic aliases are admitted; cycles, proxies, custom/null prototypes,
typed arrays/buffers, dates/maps/sets, accessors, symbols, hidden fields, sparse
or extended arrays, undefined, BigInt and functions refuse before serialization.
Frozen enumerable data is admitted; descriptor flags are not packet semantics.

Before full encoding, inspect the complete admitted graph using direct object
identity, a bounded seen/active set and fixed ceilings: depth32,8192 containers,
32768 own data edges. Charge conservative wire capacity:16 bytes per scalar or
alias reference;32+4*UTF16-code-unit length per string/key;64 per container for
tags, length integers and end markers. Array keys are charged even where V8's
dense representation omits them. These charges exceed fixed Node22.19 encoding
tags/varints/double payloads. Saturate at the requested64..2097152-byte bound;
never encode a graph whose conservative capacity exceeds it. Actual wire length
must also be at most the admitted capacity, or stop with CAPACITY_MODEL failure.
No smaller configured bound can increase any limit.

After detachment, revalidate the graph and compare EVERY own numeric data leaf
as an MSB-first binary64 word, including signed zero, along with every key,
string, primitive and property order. Compare each shared object's data once
and prove a bijection of source/detached object identities: aliases cannot split
and distinct containers cannot merge. No mutable container may be shared with
the source. No number is normalized or reconstructed from JSON sidecars.

subnormals, normal extrema and maximum finite values; Unicode/unpaired
surrogates/control strings; alias/ownership mutation; frozen values; all48 saved

and arrays; nonfinite/sparse/extended/cyclic/prototype/typed/accessor/symbol/proxy
and unsupported primitive rejection; and encoded-buffer ownership.
Saved JSON tests prove only words present in those captured trees. Root must
later supply LIVE prepared packets and verify all live words before pipeline use.
